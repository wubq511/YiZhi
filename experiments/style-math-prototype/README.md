# 图文样式与可视化公式编辑样例

这是用于核对整体视觉与公式输入体验的局部原型。2026-10-25，Robert 已接受当前版本作为后续界面的视觉基准：**手绘笔触、端正排版、内容配色必须同时保留**，不能在调整其中一项时移除另外一项。字体与符号沿用原 A 方案。Excalidraw 默认浅色样式用于画板背景与系统按钮；学习内容、知识框和笔记按信息含义配色。主题切换与自定义留到后续。

## 打开

macOS 双击 [启动样例.command](启动样例.command)，会启动本地服务并打开浏览器。保持终端窗口运行；按 `Ctrl-C` 关闭服务。

也可以在本目录运行：

```sh
python3 start.py
```

默认使用空闲端口，终端会显示具体地址；`--port 8766` 可指定端口，`--no-browser` 可只启动服务。页面需通过这个 HTTP 服务打开，服务范围为上一级演示目录，用于复用已有的中文字体。

## 当前效果与操作

[当前画板截图](preview-current.png)保留 A 的中文手写字体与数学符号，文字、标签和整体框体端正排列；知识框、笔记框、电路、关系箭头和重点下划线使用轻微起伏、复描的手绘笔触。框体不整体旋转，文字与公式不变形，连接点保持稳定。画布为白色，系统面板、按钮及公式键盘使用统一的白色与浅灰底色，淡紫色用于系统交互状态。

学习内容使用三组协调的颜色：蓝色关联选择端与输入条件；青绿色贯穿选中的信号路径、输出公式和验证结果；暖黄色区分个人笔记。知识框采用浅底色和较深边框，标题、关键符号使用深色强调，说明文字保持清晰对比。笔记与输入公式分别占有明确位置，避免混在一起。颜色配合标题和标注使用，不表示掌握程度或重要性。

拖动画板空白处移动，滚轮或左下角按钮缩放，“看全图”恢复整体视野。当前页面不提供 A/B/C 或主题切换。

点击画板中的公式或右上角“编辑公式”，可以通过字母、数字、逻辑符号和结构按钮输入，直接看到画板更新。例如：清空 → F → 等号 → 上划线 → z。分式、上下标和根号提供可填写空位；“下一个空位”用于移动。支持撤回、重做及更多符号键盘，不要求输入 LaTeX 源码。[编辑截图](preview-editor.png)

“给自己的提醒”可以直接点入修改；“重置样例”恢复原公式和笔记。

2026-10-25 核对的 Excalidraw 官方依据：[默认画板状态](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/appState.ts)为浅色、白画布、关闭网格；[浅色主题定义](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/css/theme.scss)使用白色面板、浅灰表面和淡紫色选中状态。原型的背景和系统控件沿用这套基础；学习内容另按含义配色，并保留已经选定的 A 字体与公式样式。

原比较截图保留作为设计记录：[A 手帐推演](preview-a.png)、[B 黑板推导](preview-b.png)、[C 工程草图](preview-c.png)。这些是修正前的样例，不是当前主题功能。

## 范围与验证

样例固定选择端 `xy=01`、`I₁=¬z`，所以 `F=¬z`，对应 `z=0/1` 时 `F=1/0`。其他输入只作为未选中线路展示。

本原型没有连接 Agent 或正式课程数据；公式修改仅验证编辑和显示，不会重新计算电路、真值表或说明。所有修改保留在当前页面内，刷新即恢复。Kimi 正式知识数据现已交付，知识呈现讨论在设计记录中继续；本样例仍只作为已接受的视觉与公式编辑基准。

2026-10-25 前轮在桌面 Chrome 中实际检查：原三种方案切换；点击符号组成 `F=¬z`；分式两个空位输入；撤回与重做；扩展键盘展开与收起；编辑器关闭与样例重置；画板拖动、缩放和恢复全图。启动脚本的空闲端口分配与 HTTP 页面加载通过。

本轮确认画布为纯白且无点阵，框体、笔记与关系标签均无旋转；实际点选输入 `F=¬z` 成功，公式面板与扩展键盘采用统一浅色配色。打开编辑面板时画板按可用宽度保持中心，当前默认视野下输出框完整可见；关闭面板后恢复原视野。页面运行未记录错误。移动端与正式持久化流程不在本次验证范围内。

内容配色修正后，已再次检查完整画板与打开编辑器时的效果：背景与系统按钮仍为白／浅灰；笔记与输入条件不重叠，笔记在当前视野内完整显示。抽查的条件、结论、笔记标题和笔记正文四组文字配色，对比度为 5.75:1 至 7.53:1。输入条件的公式入口仍能打开对应编辑器。

恢复手绘笔触后，已在全图与放大视图中检查线条和文字；框体、文字和关系标签无旋转。实测增加笔记行数后手绘框随内容变高，框层不拦截点击；固定种子生成的静态路径不会在编辑文字时随机改变。

## 文件与依赖

- `index.html` / `style.css` / `app.js`：原型页面、样式与交互。
- `generate-sketches.cjs`：使用固定随机种子生成静态手绘 SVG；调整笔触后可运行 `node generate-sketches.cjs` 更新页面。页面已包含生成结果，日常打开不需要执行此命令。
- `vendor/roughjs/`：Rough.js 4.6.6 的生成工具与许可；用于生成 SVG，不由浏览器运行时加载。
- `vendor/mathlive/`：MathLive 0.111.1 的本地运行资源及数学字体。
- `handwriting.css`：复用相邻 `mux-skill-comparison/excalidraw-runtime/fonts/Xiaolai/` 中的已有中文字体分片；复制样例时需保留这个相对目录关系。
