# 第三方资源

| 资源 | 来源与使用方式 | 许可 |
| --- | --- | --- |
| MathLive 0.111.1 | [MathLive](https://mathlive.io/)，从官方 npm 包提取本地运行脚本与样式；原型的可视化公式编辑与公式显示 | [MIT 原文](vendor/mathlive/LICENSE.txt) |
| Rough.js 4.6.6 | [Rough.js](https://github.com/rough-stuff/rough)，从官方 npm 包提取 CommonJS 包，用于生成框线、电路、箭头和标记的静态手绘 SVG | [MIT 原文](vendor/roughjs/LICENSE) |
| MathLive 随附 KaTeX 字体 | npm 包内 `fonts/*.woff2`，保留原字库及其字体元数据 | [SIL Open Font License 1.1](licenses/KaTeX-fonts-OFL.txt) |
| 小赖字体 Xiaolai | [上游仓库](https://github.com/lxgw/kose-font)，复用本项目现有 Excalidraw 运行资源的 WOFF2 分片；`handwriting.css` 按分片字符范围声明字体 | [SIL Open Font License 1.1](licenses/Xiaolai-OFL.txt) |

KaTeX 字体许可文件保留随附字库中的版权及 Reserved Font Name 声明，附 SIL OFL 1.1 全文。Xiaolai 许可取自上游 `OFL.txt`。本原型没有修改字库轮廓或字体名称。
