## 打开与操作

双击 [启动阅读原型.command](启动阅读原型.command)，或在本目录运行 `python3 start.py`。脚本启动本地服务并打开独立浏览器；终端按 Ctrl-C 可停止。也支持 `--port 8767 --no-browser`。运行资源、字体与来源页均在本地。

- 点击主题，先定位该主题的第一个知识单元。缩远先看到主题内单元全览，再继续缩远到主题总览；“本主题单元”和“主题总览”也可直接定位。“返回”恢复之前的视口、显示深度和阅读状态。
- 默认“滚轮缩放”：滚轮围绕鼠标位置缩放，直接拖动、空格＋拖动、中键拖动均可平移。Shift＋滚轮横向平移，Ctrl/Cmd＋Shift＋滚轮纵向平移。
- 右上可切换“触控板平移”：双指滚动用于平移，捏合用于缩放。输入方式显式选择，不猜测用户正在使用哪种设备。目录和小地图默认展开，可分别收起。
- 核心内容常驻；例题、练习、完整功能表和个人笔记通过入口原位展开。例题直接呈现讲解，练习的提示与答案手动揭示。
- MUX 可切换选择端和 z；74LS138 可切换地址与使能电平；卡诺图可以显示四角相邻示意。
- “知识关系”提供主关系、当前相关、全部关系三种显示。来源在同页显示完整原页图片，可另开大图核对。
- 复习状态由学生设置，主题汇总本页所属单元。重要性星级仍来自正式课程数据，与个人状态分开。

这是阅读原型：笔记、标记、展开和交互值保留在当前页面，刷新会重置。没有接入 Agent、课程文件持久化、完整课程搜索或正式编辑器；已有可视化公式编辑仍见相邻的 [视觉基准](../style-math-prototype/README.md)。

## 内容与依据

4 个正文样本为 `KU-035`、`KU-055`、`KU-056`、`KU-063`，另有 7 个关联单元摘要，归属 5 个正式主题。其余课程内容没有在本原型中宣称完整。

单元身份、评级与关系通过 `export-data.py` 调用统一查询 CLI 导出到 `course-data.js`，不手工维护第二套知识清单。图示和正文组合用于本次阅读验证，不写回正式知识数据。更新只读快照可运行 `python3 export-data.py`；该命令也将已有 Rough.js 依赖包装为本地浏览器资源。

来源完整页、题解性质和关系核对记录见 [source-review.md](sources/source-review.md)。页面区分官方答案、据题干推导的答案与依据同一方法编制的自测变式。`KU-063` 没有已审核关系，原型未为其补线；`REL-011` 保留卡诺图与代数法的可替代路线含义。

首次原页核对发现并修正两处权威数据的转录错误：`KU-056` 例题第三项改为 `A′BC`；`MAP-153` 地址位改为 `A15/A14/A13 → A2/A1/A0`。统一构建已更新派生产物，源检查、构建后检查及原有 15 项 unittest 均通过。

## 阅读顺序与缩放设计

主题按课程脉络从左到右、再从上到下组织。单元位置依据已审核关系安排，目录采用同一阅读顺序：

- 卡诺图先读 `KU-034` 排列与相邻规则，再读 `KU-035` 圈组化简。`KU-036` 覆盖优化与 `KU-037` 多图邻接位于右侧的两个分支。
- 无关项化简与或-与式是圈组方法的不同扩展；组合逻辑设计保留代数法和卡诺图法可替代的条件。
- MUX 先读 `KU-055` 功能，再向右分别进入 `KU-056` 函数实现和 `KU-057` 级联扩展，不把后两者连成前置链。
- 74LS138 独立组织使能、地址和输出的讲解，没有为视觉布局增加知识关系。

正文按理解与使用的顺序连续向下阅读。图、控制和结果相邻；例题顺着解题步骤展开。摘要中的生硬拼接已改为完整句子，必要术语在首次使用时说明。

三个显示深度共享同一组知识坐标。中间的单元全览显示标题、摘要和关系；切换深度不重新排列卡片。进入主题定位首个单元，返回可恢复其他已读单元。中间层阈值按本主题内容范围与可用视口计算，避免用一个固定百分比过早隐藏 B。

## 画板操作的参考与实现

实际核对了 Excalidraw 官方源码（固定版本 `b7de45e88111f5680ae4bb3c3f3541c7d3b279fe`）：[wheel 与输入模式](https://github.com/excalidraw/excalidraw/blob/b7de45e88111f5680ae4bb3c3f3541c7d3b279fe/packages/excalidraw/components/App.wheel.ts)、[指针锚定](https://github.com/excalidraw/excalidraw/blob/b7de45e88111f5680ae4bb3c3f3541c7d3b279fe/packages/excalidraw/viewport.ts#L203-L227)、[拖动调度](https://github.com/excalidraw/excalidraw/blob/b7de45e88111f5680ae4bb3c3f3541c7d3b279fe/packages/excalidraw/components/App.pan.ts)。

借鉴了明确区分输入模式、Ctrl/Cmd+wheel 接收捏合、先限制缩放值再计算指针锚点，以及空格和中键拖动的处理。本原型默认普通滚轮缩放，另提供触控板平移模式。缩放采用限制单次变化的连续比例曲线，分别处理普通滚轮和捏合的灵敏度，并换算 `deltaMode`；没有直接复制 Excalidraw 的步长数值。

相机累积每次输入的变化，每帧统一绘制；小地图的节点只在布局、层级或选中项变化时重建，平移缩放时只更新视口框。关系和手绘框也不在每次指针移动时重新生成。

## 当前验证结果

在桌面 Chrome 实际操作，验证通过：

| 场景 | 观察结果 |
| --- | --- |
| 阅读入口与布局 | 卡诺图主题从排列与相邻规则开始；目录与画板顺序一致，基础在左、应用及扩展在右，并列分支向下安排 |
| 逐步缩远 | 从 MUX 阅读位置连续缩远，先进入单元全览；约 14%、12%、10% 时三个 B 均完整可见，继续到约 8% 才切为 A；这些是当前窗口的观察值，不是固定切层常量 |
| 直接看本主题 | 卡诺图的 4 个 B、MUX 的 3 个 B 可完整进入视口；缩放期间单元坐标保持不变 |
| 滚轮与拖动 | 一次实际滚轮操作使缩放由 0.86 变为 1.13789，指针锚点误差小于 0.01 屏幕像素；拖动 100×120 像素得到对应平移，缩放不变 |
| 平移模式 | 滚动使画板纵向平移 141 像素，缩放保持 1.13789；画板内部没有浏览器自动滚动偏移 |
| 展开与返回 | 卡诺图例题展开后，入口屏幕位置、视口和右侧分支位置不变；查看主题内单元再返回，展开状态和相机变换完全恢复 |
| MUX 交互 | 选择 01 时切换 z，输出由 1 变为 0，与接线和公式一致 |
| 74LS138 交互 | 地址 001 且使能满足时，第 1 路为 0；把低有效使能端的实际电平改为 1 后，8 路输出全部为 1 |
| 关系与运行 | 全部关系显示 8 条已审核边及 8 个说明项；当前页面无控制台错误、重复 ID 或公式渲染错误 |
| 文字与视觉 | 四个正文样本和七个摘要按阅读顺序整理；图与操作相邻，所有主题卡文字均落在框内；手绘笔触、端正排版、内容配色保留 |

物理触控板的捏合手感、中键硬件操作和 Safari 的原生手势分支未单独验收；已实现相应输入路径，不将本轮 Chrome 的滚轮检查等同于所有设备体验均已通过。
