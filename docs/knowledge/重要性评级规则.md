# 重要性评级规则

状态：知识单元 B 与知识主题 A 的规则均已确认。

## 1. 评级含义

“重要性”统一表示复习资源分配与知识支撑作用，使用一至五星表示。它不是考试命题概率、题目难度或个人掌握程度，也不另设一个含义重复的“重点程度”。

评级必须附证据。星级用于快速比较，证据用于审计和后续调整。

## 2. 证据顺序

本课程按以下顺序使用证据：

1. 老师明确指定的考前习题课：具体解答例题与“基本题型”清单分开记录。
2. 课后作业中的直接考查。
3. 教师课件中的明确讲解、练习与强调。
4. 知识单元对后续内容的支撑作用。

教材用于校准具体知识表述，笔记只作参考；二者都不独立决定考试范围或重要性。

不能由“没有作业”推出“不考”，也不能由原始出现次数直接推出五星。

## 3. 知识单元 B 的五星锚点

| 重要性 | 判定锚点 |
| --- | --- |
| ★★★★★ | 习题课有对应解答例题；或习题课明确列出、又被作业或多个设计任务反复考查的核心内容 |
| ★★★★☆ | 习题课“基本题型”直接点名，或课后作业直接考查；包括必须熟练使用的模块与方法 |
| ★★★☆☆ | 课件有明确讲解或练习，并直接支撑上述题型，但缺少直接题目证据 |
| ★★☆☆☆ | 课件中的细节或背景知识，对综合题只有间接支撑 |
| ★☆☆☆☆ | 介绍性、拓展性内容；保留索引，但不建议优先投入复习时间 |

## 4. 调整与计数约束

- 习题课解答例题的证据高于普通作业，但答案中出现的每个公式不都构成独立重点。
- 习题课“基本题型”是范围与重点证据，不与具体例题混算出现次数。
- 跨主题的强支撑作用可上调一级，必须写出理由；不根据依赖数量机械加分。
- 同一道题重复使用同一单元，统计题目覆盖时只计一次；所有小问仍保留映射以便回查。
- 只有“直接考查”用于作业重点证据，“前置支撑”不能被等同计数。
- 评级在题目映射之后进行，避免先打星再寻找理由。

## 5. 知识主题 A 的评级（已确认）

### 5.1 评级结构

主题整体重要性按 **A 自身的核心学习表现和主题层证据** 独立评定，不使用 `max`、平均值、加权平均、高星比例或图中心性从 B 计算。

同时保留两个由 B 自动计算的摘要：

- **单元峰值**：`max(B)`，只表示主题内最高单元优先级。
- **星级分布**：各星级单元数量，只表示清单构成和覆盖广度。

主题整体星级用于主题之间排序，单元星级用于单元之间排序。不要附加 `A ≥ max(B)`；整体星级低于单元峰值并不矛盾，因为二者评价的对象不同。

### 5.2 前提：主题必须可被评价

每个 A 先写一句范围与核心学习表现，例如“能将逻辑功能转换为所需电路，并验证其正确性”。证据必须覆盖这个核心，而不是只覆盖主题中的一个局部或边缘单元。

如果 A 只是为方便导航拼凑的容器，无法写出统一的核心学习表现，应先调整主题边界。确实不需要整体评级的导航容器，只展示单元峰值与分布，不伪造主题星级。

### 5.3 主题层五星锚点

| 主题整体重要性 | 判定锚点 |
| --- | --- |
| ★★★★★ | 习题课的解答例题直接覆盖 A 的核心学习表现；或习题课明确列出该核心，且它又被作业或多个设计任务反复直接考查 |
| ★★★★☆ | 习题课“基本题型”直接点名 A 的核心学习表现，或课后作业直接考查该核心，但未达到五星证据 |
| ★★★☆☆ | A 的核心有明确课件讲解或练习，并直接支撑核心题型，但缺少直接题目证据 |
| ★★☆☆☆ | A 主要提供细节或背景，对核心题型只有间接支撑 |
| ★☆☆☆☆ | A 主要是介绍性、拓展性内容；保留索引，但不建议优先投入复习时间 |

跨主题的强支撑作用可以上调一级，但必须写出具体理由。只考查一个局部 B 的题目不能自动算作 A 整体的直接证据。

### 5.4 评定步骤

1. 写出 A 的范围与核心学习表现。
2. 建立主题证据卡，记录习题课、作业、课件和跨主题支撑的位置，继续区分直接考查与前置支撑。
3. 判断证据覆盖的是主题核心还是局部细节，再按主题锚点评级。
4. 写一句可审计的主题评级理由，不从 B 的数值反推。
5. 自动计算单元峰值和完整星级分布，与主题整体星级并列展示。
6. 假想拆分或合并一个 B；若 A 的整体星级仅因清单组织变化而波动，应回到主题证据重新判断。
7. 至少检查“单个五星加大量背景”“多个四五星”“只有间接支撑”“跨主题强支撑”四类边界案例。

### 5.5 调研依据与边界

外部调研没有提供课程主题重要性的通用公式，但支持目标与评价对齐、保留底层证据、谨慎处理权重与聚合，以及不把图中心性等同于考试重要性。完整来源、方案比较和局限见[主题重要性评级调研](../../courses/digital-logic/期中/设计/调研/主题重要性评级调研.md)。

## 6. 每个评级的审计字段

- 知识单元或主题 ID。
- 星级。
- 习题课证据：基本题型、具体例题及 PDF 页码。
- 作业证据：题目、小问及“直接考查 / 前置支撑”角色。
- 课件证据：讲解、练习或强调位置。
- 支撑作用调整：是否调整、调整理由。
- 最终一句话依据。

主题还需保存各星级单元数量；数量由正式清单计算，不能手工填写后长期不同步。

## 7. 复核清单

- [ ] 星级与证据分开呈现。
- [ ] 每个五星和四星单元都能回查到题目或明确的范围依据。
- [ ] 每个上调一级的单元都有文字理由。
- [ ] 没有将难度、掌握程度或原始频次混入重要性。
- [ ] 没有因缺少作业而删除课件内容。
- [ ] 主题星级符合最终确认的规则，星级分布由单元数据计算。
