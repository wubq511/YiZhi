# 知识点拆分规则

状态：已确认  
适用：数字逻辑期中整理；方法可复用于其他课程的资料索引与知识地图。

## 1. 目标

拆分结果首先服务于资料索引、题目映射和关系整理，而不是直接替代完整讲义。合适的粒度应让人能定位来源、判断掌握情况，并把一道综合题映射到多个知识单元。

## 2. 层级

| 层级 | 定义 | 用途 |
| --- | --- | --- |
| 课次 | 教师资料的来源分组 | 导航与回溯，不直接视为知识点 |
| 知识主题 A | 按内容归纳的较粗分组 | 组织知识单元、展示主题评级 |
| 知识单元 B | 可独立考查并判断掌握程度的知识或操作内容 | 清单、题目映射、重要性和关系图的基本节点 |
| 单元内部项 | 定义、公式、方法变体、易错点、例题定位和来源页码 | 支撑复习，不全部进入关系图 |

知识主题不是把课件标题换个名字；知识单元也不是课件页面、公式或题目的同义词。

## 3. 知识单元的三种类型

| 类型 | 核心问题 | 示例 |
| --- | --- | --- |
| 概念与规律 | 是什么，有什么性质或成立条件 | 无关项、传播延迟、溢出规律 |
| 方法与技能 | 怎样完成一种可检查的操作 | 代数法化简、卡诺图化简、组合逻辑分析 |
| 模块与器件 | 模块有什么功能，端口和控制条件怎样使用 | 复用器、74HC138、74LS283 |

同一个主题可以包含不同类型。例如“译码器”主题下，“74HC138 的端口与有效电平”是模块与器件，“用译码器实现组合逻辑”是方法与技能。

## 4. 拆分流程

1. 从教师课件、考前参考题和作业中提出候选内容，不从教材目录反向扩充范围。
2. 把候选内容改写成一个可回答的问题或一项可检查的任务。
3. 标注“概念与规律 / 方法与技能 / 模块与器件”。
4. 检查它能否单独成为一道题或一个明确小问，并能独立判断会与不会。
5. 比较目标操作、方法步骤和前置知识；存在实质差异时才继续拆分。
6. 把更低层的公式、参数变化、方法变体和例题保留在单元内部。
7. 记录来源、题目映射和评级依据，再决定它与其他单元的关系。

## 5. 拆分与合并标准

### 应当拆分

满足至少一项，并且拆分后能形成清晰的独立检查标准：

- 能由不同题目或小问独立考查。
- 目标操作不同，例如“识别器件功能”与“用器件设计电路”。
- 方法步骤实质不同，例如普通卡诺图化简与多输出共享乘积项化简。
- 所需前置知识不同，拆开后才能准确表达依赖。
- 教师考前资料将其明确列为独立基本题型或独立操作。

### 应当合并或留在单元内部

以下变化本身不足以产生新单元：

- 同一方法只改变变量名、位数、参数或表达式外观。
- 同一结论只改变公式形式或例题。
- 拆分后不改变题目映射、前置关系或复习检查方式。
- 只是把一页课件、一个公式或一个题号机械转换成一个节点。

若位数变化引入了新的操作方法，不应继续机械合并。例如多图卡诺图的跨图邻接应至少保留为显式变体；是否独立成知识单元，再由独立考查证据和前置差异决定。

## 6. 停止条件

一个候选单元同时满足以下条件时停止拆分：

- 能用一句话说明“需要会什么”。
- 能给出少量可检查的掌握标准。
- 继续拆分不会新增独立题目映射或不同的前置关系。
- 单元内部仍能清楚保留公式、变体和来源，不会丢失课程细节。

不预设全课程必须有多少个节点，也不以“每章数量一致”为目标。

## 7. 本课程边界示例

| 候选内容 | 处理 | 理由与来源 |
| --- | --- | --- |
| 普通卡诺图化简 / 含无关项化简 / 多输出共享化简 | 分为不同方法单元 | 操作目标和选取规则不同；习题课 PDF 第 3 页分别列出 |
| 2–4 变量普通卡诺图 / 5–6 变量卡诺图 | 前者可共用单元，后者保留多图邻接变体，按证据决定是否独立 | 第 03 课 PDF 第 4–21 页；位数本身不是拆分理由，新邻接操作才是 |
| 原码、反码、补码的表示与转换 / 补码加减与溢出 | 分为表示方法和运算方法 | 第 01 课 PDF 第 35–45 页；习题课 PDF 第 2 页同时提到表示与加法运算 |
| 74HC138 的端口与有效电平 / 用译码器实现组合逻辑 | 分为器件单元和方法单元 | 第 05 课 PDF 第 35、38–43 页；习题课 PDF 第 4、17 页 |
| 二选一 MUX 的多种描述方式 / 用 MUX 实现逻辑函数 | 本课程排除 HDL 后，只保留后者及必要的电路原理 | 当前范围排除 SystemVerilog/HDL，不能因课件含代码页而删掉整个模块主题 |

## 8. 反模式

- 把“复用器”一个大标题直接当成最小知识点。
- 每个公式、每种表达式、每道例题都建立节点。
- 为凑齐四种题型而强行移动知识单元。
- 因为教材存在相关内容，就加入教师资料未覆盖的单元。
- 因为没有作业，就删除教师讲过或习题课列出的内容。
- 把课次先后、解题步骤先后或主题归属当作知识前置。

## 9. 复核清单

- [ ] 每个知识单元都能独立说明“需要会什么”。
- [ ] 每个知识单元都有类型和可回溯的教师资料来源。
- [ ] 拆分依据是独立考查、操作或前置差异，不是页面和公式数量。
- [ ] 单元内部没有丢失影响解题的变体、条件和有效电平。
- [ ] 综合题可以映射到多个单元，没有被迫只选一个。
- [ ] 排除项与课程设计文档一致。
