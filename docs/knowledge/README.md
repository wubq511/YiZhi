# 知识方法与课程依据

这里保存整理规则、课程范围和核验依据。实际课程知识、原始资料及学习状态在 [课程目录](../../courses/digital-logic/README.md)，查询与维护工具在 [tools](../../tools/README.md)。

| 文档 | 职责 |
| --- | --- |
| [知识点拆分规则](知识点拆分规则.md) | 主题与单元的层级、拆分与合并标准、停止条件及边界示例 |
| [重要性评级规则](重要性评级规则.md) | 证据优先级、单元五星锚点、主题独立评级和审计要求 |
| [数字逻辑课程基线](数字逻辑课程基线.md) | 20 主题与 84 单元的范围、稳定结构、来源用途、纠正与尚存证据缺口 |
| [教材检索与核验](教材检索与核验.md) | OCR、中文书页与 PDF 页序、校准目录、跨页习题及原图核验 |
| [主题评级研究](../research/topics/知识组织/主题重要性评级依据.md) | 独立评级、峰值、平均、比例及中心性的比较与原始文献 |
| [内容审校聚合证据](evidence/digital-logic-content.json) | 最后主题结论、计算核验、导入回执、早期修正与失败记录；不作为第二份课程正文 |
| [两份审校原件](evidence/source-review/) | 保持原始字节和哈希的早期 accepted 输入，历史路径映射见课程基线 |

新课程先明确资料范围与排除项，再按拆分规则建立知识、完成题目映射、依据证据评级，最后审核关系实例。不能按教材目录补全课程，也不能用章节顺序代替前置关系。已有完整课程直接作为开发基线，目录整理不重新抽取知识。

同一方法只在对应规则文档维护；具体课程的约束与核验放在课程基线中，课程目录不重复存放设计、任务和交接文件。
