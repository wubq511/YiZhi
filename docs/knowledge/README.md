# 知识整理方法

用于把课程资料整理为可核查的知识清单、题目映射和知识关系图。这里保存可复用的方法；具体课程的范围、证据和交付状态保存在课程目录中。

## 规则文档

- [知识点拆分规则](知识点拆分规则.md)：知识主题与知识单元的层级、拆分与合并标准、停止条件及边界示例。
- [重要性评级规则](重要性评级规则.md)：证据优先级、知识单元五星评级、主题评级算法及审计要求。

## 使用顺序

1. 先在课程设计文档中确定资料范围、排除项和证据来源。
2. 按拆分规则建立知识主题与知识单元，不先按教材目录补全内容。
3. 完成题目到知识单元的映射，再依据证据评定重要性。
4. 确认关系类型后生成关系实例和图，不能用章节顺序代替前置关系。

## 维护边界

- 通用规则只在本目录维护，课程文档链接到这里，不复制一套规则。
- 课程专用的资料名称、题型和证据权重记录在课程设计文档中。
- 已确认规则与待确认建议必须标明状态；后续讨论不得把建议静默写成事实。
- 当前课程实例：[数字逻辑期中整理](../../courses/digital-logic/期中/README.md)。
