## 使用与定位

以下命令从 YiZhi 仓库根运行。查询只需要 Python 标准库；原页渲染需要 Poppler 的 `pdftoppm`。

```bash
python3 tools/digital-logic/textbook/教材.py verify
python3 tools/digital-logic/textbook/教材.py toc '卡诺图'
python3 tools/digital-logic/textbook/教材.py section 2.7
python3 tools/digital-logic/textbook/教材.py search 5.55 --chapter 5 --scope exercises
python3 tools/digital-logic/textbook/教材.py read 42-44
python3 tools/digital-logic/textbook/教材.py read 56-58 --pdf
python3 tools/digital-logic/textbook/教材.py render 42-44 --out /tmp/textbook-pages
```

检索同时查校准目录和 OCR，并区分命中来源。关键词忽略空白及英文大小写；数字题号按边界匹配，避免 `5.5` 混入 `5.55`、`15.5` 或 `5.5.1`。题号之间的换行保持分隔，编号内部允许空格，摘录保留原始大小写与换行。

查习题时使用 `--scope exercises`，限定章末习题区并包含共享边界页，优先显示题号位置候选。能识别同页下一题时，按 OCR 坐标重排当前区域；下一题号缺失、不连续或题目跨页时，明确提示继续看相邻页。无命中可回退 `--scope all`。这些摘录用于定位，题目边界、引用及精确内容仍须核对原页。

`section 1` 至 `section 8` 包含整章、章末习题和面试问题。小节按整页范围读取，可能带入相邻节，不是精确段落切分。习题入口如 `5-exercises`；附录入口为 `A`–`D`，附录内部小节需在正文检索。

## 页码与数据

| 名称 | 含义与换算 |

原始 OCR 与章节文本承担不同的检索和阅读用途。OCR 没有用语言模型补写、解题或猜符号；识别置信度不是实测准确率。原始 PDF 保持不变。

## 覆盖与已修复问题

初检 495 页均无可提取文字层。本地 Apple Vision 中英文 OCR 覆盖 495/495 页，逐页连续且均有文本，共 647,649 个字符（含换行）；字数不表示准确率。16 份 Markdown 覆盖 PDF 1–495，每页恰好一个稳定锚点。目录检查包括编号唯一、起始页单调、范围有效及对应文件存在。

中文页码映射在 452 页得到 OCR 页眉数字支持；剩余 28 页实际检查原图页首，属于章首页不印页码、漏识别或数字误识，未发现页序跳变。检查了 8 个章首页、4 个附录首页，确认 PDF 494 页眉为 480、495 为封底。另实际渲染 PDF 56，确认中文书页 42 与 2.7 标题。

| 发现的问题 | 修正与可验证结果 |
| --- | --- |
| 把章末习题列为一级目录，使 `section 5` 截止 PDF 188 | 章末项目归入二级；第 5 章完整范围为 PDF 160–194，8 章均按页码映射核对完整覆盖 |
| OCR 漏标题、同号例题先于习题命中 | 同时查独立目录与 OCR，增加习题区筛选及题号位置排序 |
| 数字题号误匹配，代码摘录大小写和换行丢失 | 使用编号边界并保留原始摘录格式；相邻题号不拼接 |
| 固定字符窗口将邻题混入、截掉本题小问 | 用逐行坐标生成题号区域候选；无法确认同页边界时不声称完整 |
| 原件或索引变化后仍可能沿用旧结果 | 每次命令核对原 PDF 摘要及实际读取文件；`verify` 校验全部索引、页号、锚点与整章范围；构建前拒绝新原件配旧 OCR |

当前 14 项回归覆盖上述问题、中文／PDF 页码等价、共享边界页、非法参数和模拟原件／OCR 变更后的拒绝行为。2026-10-28 工具迁出课程目录后，14 项回归及全量 `verify` 再次通过。目录校准文件只改变存放路径，原始 OCR、章节文本和 PDF 没有重建。

旧 `search 2.13 --chapter 2` 首先返回中文 49／PDF 63 的“例 2.13”；加 `--scope exercises --limit 1` 后返回中文 56／PDF 70 的习题。PDF 193 的 OCR 将 5.55、5.56、5.57 题号聚集，再输出题干；坐标候选修复了邻题混入，并完整显示 5.55 的五项引用。2.13 与 2.35 的跨页提示继续保留。

这次核对确立的阅读规则是：先确认目标题边界，再逐项追踪真实引用，分别保留本题改变的规模与引用题的定义。以上是阅读条件与出处验证，不是全书逐字校订。

## 有必要时才重建

普通使用直接读取现有索引。只有对照原页修正 OCR 或目录源数据后，才运行 `tools/digital-logic/textbook/构建索引.py`，随后执行 `教材.py verify` 和 `test_textbook.py`；构建需要 `pypdf`。不能为了消除摘要不匹配而盲目重建。

`tools/digital-logic/textbook/ocr.swift` 保存原 Apple Vision 处理实现，需要 macOS、Swift 和 Vision，接收原 PDF、输出目录、起止页四个参数。它跳过已存在的逐页 JSON，适合中断续接；更换原件、识别参数或引擎时使用新的空输出目录，避免混用。临时编译文件与渲染图用后清理。

已观察到中文错字、上下标与反相线丢失、图文混排及双栏乱序。附录只校准一级入口，没有建立精确题目边界索引，也未测量全书 OCR 准确率。公式、真值表、电路、时序图、代码和精确引用仍以原页为准。
