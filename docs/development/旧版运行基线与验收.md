## 4. 必须带入后续开发的回归经验

### 保存、并发与任务恢复

- 事务成功与任务记录成功有不同故障窗口：正文已提交、task 的 operationIds 保存失败时，重开要从持久账本补回关联；不能仅相信 task 缓存。首次 task INSERT 失败不能留下“幽灵任务”，相同 requestId 要能重新持久化并启动，草稿/掌握状态不能先丢失。
- 已有一次成功提交不代表整个任务完成：剩余块冲突仍为 needs_input。停止后迟到新提交拒绝，但重复已提交工具调用应返回原回执（包括 knowledgeChanges）并保留后续学生编辑。
- 断线不覆盖已经保存的部分回答；重开如查询到同 turn 已完成，要恢复完整 agentMessage，不能要求重跑。item/completed 已提供全文后忽略同 item 的迟到 delta，避免“完整回答回答”。
- steer accepted 只证明通知接收，最终仍须修订/块比较；通知失败要记录 accepted=false/error，后续重读可继续，但不能虚称已通知。不同块可兼容整合，同块冲突不得猜测字符级合并；目标在排队和切换 UI 后仍固定。
- 整幅恢复产生新 generation，哪怕实体内容和旧版本相同，也拒绝恢复前任务的提交。重开只 reconcile，显式继续携带 alreadyCommittedOperationIds，补未完成意图。
- JSON 与 SQLite 需共同恢复：已验证 after_journal、before_replace、after_replace、before_sqlite_commit、after_sqlite_commit 进程退出，重开为完整旧或新状态。恢复保留无关外部导入；同片段外部变化则保留文件/journal并报精确路径，不强制覆盖。真实 SQLite trigger/COMMIT、rename/fsync 故障不能只用内存异常替代。
- 多浏览器编辑、依赖对象 CAS、墓碑身份不复用、同 ID 不同载荷拒绝、丢回执同命令重试，均是保存保证。advisory lock 只约束合作写入者，原生旧导入 CLI 的并发窗口仍存在；具体入口见接口。

以上竞态由真实 CourseService/ContentCommands/SQLite/临时课程加执行器端口替身定向覆盖；历史首次 Runtime 18 项中 7 项失败已由主线修复并回归。不能把可控故障注入写成真实模型逐项碰到这些故障。

### 正文、原页与搜索

- 最终审查去重后 4 项 P2 已关闭：单来源缺失不得拖垮知识/笔记/对话搜索；对话索引真实消息并提供 messageId；深层知识命中保留 blockId 并展开父级/答案；导入在 I/O 边界检查实际图片、manifest、SHA 与路径，不能只过 schema 就接受缺图。缺失来源按版本隔离告警，修复文件后索引自行恢复；未搜原文不显示无关来源告警。
- 共享题解与完整 children 同时显示会重复解答：有完整 children 连续读它，无 children 才回退共享题解。原页 figure 限宽并保持比例，不能突破卡片。
- CSS transform 平移的画板中，原生 lazy 图片可能一直 0×0；KU-014 已重现，正文图改普通加载与异步解码，由 ResizeObserver 更新布局。不要把源码有 URL 当作图已可读。
- 原页图加载两类故障分别定位：热缓存 12 并发仍有 connection reset，TCP 等待队列旧值回归重现后将 `request_queue_size` 调到128；另一个 `page_image` 窗口是公开文件写到一半就被命中、同页重复渲染、失败者删除其他发布者缓存。后者独立红测后用实例内每页锁、同文件系统私有目录生成、成功后原子发布，失败只清自己的私有输出。不能拿后者替前者归因。
- 缓存命中前仍校验资料路径、版本摘要和页码。锁只对同一 SourceLibrary 实例线程去重，不同实例/进程可能重复渲染；未增加 PNG 解码验证，也不自动修复已有坏缓存。超时、工具缺失、OSError、无输出及非零退出统一报 source_unavailable，失败后可重试；不同页不全局串行。

### 编辑、锚点与渲染接缝

- provider 的外层/内层共用 reading-interactive 类曾令初始化对无配置外层执行 JSON.parse(undefined)，中断应用；组件初始化只处理所属区域和实际 data-component，保持幂等，不重绘别的模块。交互输入与展开/答案通过同一阅读保存机制恢复。
- 编辑器必须保留**读取时**原始实体/hash/revision/generation和个人布局修订；恢复草稿不能偷换最新基线。关系生成 ID、语义标记和最终 CAS 载荷在第一次 POST 前冻结，丢回执重试不能重新分配 ID 或改变命令。
- `.frame > :not(.sketch-border){position:relative}` 曾压过编辑 overlay 的 absolute，SVG 回到正文流，ResizeObserver 相互放大：20帧 KU-055 高度从6854增到42050。隔离 selector、inline结构约束及 absolute/contain/clip，取消实测高度反写后20帧均1665px。这是实际主线页面高度检查，不能把独立 host 的重新挂载当作同一种验收。
- 图形与其布局原子提交；pointerup 才保存，Escape/pointercancel 为零命令；箭头翻转保留方向。标注跟随稳定 block ID，不用派生 hint/answer DOM ID 当新知识身份；来源读取失败不能误判对象删除。
