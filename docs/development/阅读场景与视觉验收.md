## 2. 判据：先分语义，再选表达通道

学习任务是目标，手绘、字体、公式、图表、空间、标注和颜色共同服务理解。不能从界面外观反向猜测知识或审核结论。

| 独立维度 | 验收时必须分清 |
| --- | --- |
| 知识结构 | 主题 A、单元 B、单元内部项；概念／方法／模块影响正文组织，不要求三种整卡颜色；内部内容不全部升级为节点或关系 |
| 学习用途 | 检查材料支持什么学习任务；不等于表达形式、视图层级或数据类型 |
| 表达 `kind` | 决定适合的组件与交互；表格可表达定义、条件、对照或验证，`callout` 也不天然等于警告 |
| 显示 `role` | `core` 为当前理解必需，`material` 是预先备齐、按需原位展开的材料，`supplement` 是补充说明；均不代表星级，supplement 不是个人笔记 |
| 归属 | 正式课程、个人内容、Agent 内容保持独立身份；自由选色不能改变归属或产生正式知识事实 |
| 元信息与状态 | 课程重要性、个人三态、正文生命周期、未保存草稿、持久化反馈、Agent 待决策分开；高星不等于薄弱、困难或已掌握 |

`kind`、`role` 都不直接决定颜色；`kind=callout` 与 `payload.tone` 也不足以确定学习意图。理解引导、适用边界、方法警示与来源勘误须读内容区分，不按旧色批量推断类型；本文不扩展 reading schema。

### 非颜色通道的最低判据

| 要辨识的信息 | 必须同时可读的线索 |
| --- | --- |
| 条件 → 结果 | 条件／输入／使能标签、变量与当前值、路径方向、输出数值或公式、解释；控件按下不表示答案正确 |
| 方法、易错与理解引导 | 步骤号、动作、判断条件与中间结果；具体的“适用边界／易错／方法提醒”或问题句，不把疑问伪装为系统异常 |
| 例题与练习 | 例题完整解法可读；练习题目、提示、答案的揭示状态可辨；保留来源与 `answerNature`，不把官方解、推导解、自编示例和自测混同 |
| 知识引用与来源 | 前者回到知识主位置并可返回，后者核对固定版本原页；保留目标、引用意图、版本、页码及采用口径，题目映射不自动成为前置关系 |
| 正式关系与个人箭头 | 正式关系有类型、方向、`value`、来源和审核状态；个人箭头有独立入口与个人身份，不能凭线色判真伪或关系类型 |
| 前置与显示级别 | “必须／任选其一”、组成员与组 ID 明示 AND／OR；主／辅助控制密度，不代表真实性高低 |
| 笔记、状态与异常 | 笔记作者、原引用、关联状态；星级理由、完整复习状态文字；正文草稿与未保存草稿分别说明；保存状态须对应真实回执 |
| 失败与待处理事项 | 保存冲突给原因及处理动作；来源异常说明限制及替代路径；Agent 决策给理由、影响对象与明确按钮；交互失效保留“需核对”及原因 |

多语义共存时按位置分层，不用整卡换色覆盖身份：正文原位表达知识；标题／摘要／证据区承载元信息；笔记与标注保留个人层；保存、冲突与决策位于对应系统区域。
注意力顺序为：需处理的阻塞问题先可见，当前阅读保持主体，正式提醒原位可见，重要性与复习状态便于扫描，个人强调由学生控制。
关闭或去除颜色后仍须能完成辨识；不能把“所有语义各加一种色相”当作通过，也不能让个人覆盖层遮住正文或冒充正式圈组。

## 3. 六种学习用途

以下用于检查材料是否足以完成任务，不要求每个单元凑齐六种，也不新增第七种“笔记／来源／状态”用途。

| 学习用途 | 真实内容例子 | 可观察的阅读结果 |
| --- | --- | --- |
| 概念与结论 | MUX 选择规则、有效电平、溢出条件 | 能说明是什么、何时成立、得到什么；正文、公式与图相邻 |
| 结构与关系 | 电路结构、真值表、正式前置与构造关系 | 能沿位置、对应、连线、方向和标签解释组成与路径 |
| 方法与步骤 | 卡诺图圈组、MUX 数据端求法、组合设计流程 | 能按编号与判断条件执行，并检查中间结果 |
| 例题与练习 | 完整示范、自测、提示与答案 | 能先读示范再独立作答，按需揭示提示与答案并辨明答案性质 |
| 验证与探索 | 改 MUX 选择码、检查译码器使能、卡诺图跨边相邻 | 能指出改了哪个输入、输出如何变化及原因，而非只看到变色 |
| 对比与易错 | 进位与溢出、有效电平、适用边界与反例 | 能借对照、边界标签和反例避免错误迁移 |

## 4. 六个可复验场景 A–F

对象来自真实课程；**C、F 的个人／系统状态组合是脚本化压力条件，不是默认界面或已完成的真人验收**。后续优先复验 B、C、F，实际已验项目必须逐项回看第 5 节原记录。
执行前只读确认对象与内容仍存在；需要造状态时使用独立验收副本，不写真实个人数据库，不为凑场景修改正式知识。

### A：主题全览与复习资源分配

- 对象：`TH-08`“卡诺图基础与化简”，主题整体五星，含 `KU-035`。
- 任务与操作：全览主题核心学习表现、整体星级、单元峰值／分布与三态汇总，选择需要优先阅读的单元进入。
- 同屏压力：A 的独立评级、B 的重要性和个人状态、主题聚合关系同时存在。
- 通过：能解释 A 的星级并非 B 的平均或峰值；汇总不是另一份可编辑掌握状态；关系不遮标题／摘要；不靠颜色也能区分重要性与复习状态。
- 留证：记录全览与进入目标单元的画面，标明评级证据入口及状态汇总来源。

### B：概念理解与交互验证（优先压力场景）

- 对象：`KU-055`“MUX 功能与 2:1/4:1 表达式”，概念、五星；定义、两个公式、交互、例题和练习并存。
- 任务与操作：先辨选择端／数据端；依次切换选择码，再改变所选数据端，逐步对照公式、路径与输出解释。
- 同屏压力：条件、控件当前值与按下状态、选中路径、输出结果、公式和材料入口同时可见。
- 通过：每次能由输入追到输出并解释原因；按下状态不被读成“正确”；去除颜色后标签、数值、方向／线型仍够用；图、公式、解释无需跨卡寻找。
- 留证：保存切换前后输入与输出、对应公式及文字结论；颜色辨识与非颜色辨识分别记结果，不能以单张截图替代操作链。

### C：方法、正式警示与个人复习并存（优先压力场景）

- 对象：`KU-035`“2–4 变量卡诺图化简”，方法、五星；知识引用、跨边交互、步骤、完整例题与带提示练习。
- 条件：副本中设为“薄弱”，添加个人笔记及圈组个人高亮；保留正式提醒“不能只按先圈最大的圈贪心”。
- 任务与操作：回看引用，切换跨边圈组，按步骤理解必要质蕴含选择；先自测，再依次揭示提示与答案，记录疑问。
- 通过：重要性、薄弱、正式方法警示、练习提示、个人笔记及高亮六者各自可辨；个人高亮不冒充正式圈组；展开后阅读顺序和原位关联清楚，不靠整张黄卡承载全部含义。
- 留证：记录六种语义的标签／位置、交互开关与解释、提示和答案各揭示状态，以及展开前后正文是否受遮挡。

### D：器件条件、有效电平与来源核对

- 对象：`KU-063`“74LS138 端口、有效电平与使能”，模块、四星；使能表、提醒、地址公式、交互、例练及来源。
- 任务与操作：先判断使能，再改地址看输出；遇到符号疑问进入指定版本原页核对并返回。
- 同屏压力：有效电平提醒、端口／低有效标记、输出与来源反馈；如检查来源失败路径，须单独标注为注入条件。
- 通过：必要条件常驻；正式易错不被读成系统报错；来源区异常不改变正文语义；端口、标记、文字与输出足以理解，无须记颜色。
- 留证：记录使能与地址条件、输出解释、来源版本／页码及返回位置；成功和异常路径分开记。

### E：正式前置与可替代路线

- 对象：`KU-044`“组合逻辑设计流程”；关系依据查课程基线及权威知识，不从图形颜色反推。
- 条件：`KU-029` 必需，且 `G1(mode=any)` 中 `KU-033`“代数法化简”／`KU-035` 任选其一；核对 `REL-043 / REL-010 / REL-011`。
- 任务与操作：展开前置与关系详情，沿两条路线分别解释开始设计需要什么，再切换主／辅助显示范围。
- 通过：不会误读为三个都必需；AND／OR 有明确分组与文案；关系价值、来源可查，主／辅助不被理解成审核等级；个人同色箭头不能替代正式证据。
- 留证：记录条件文案、组成员、关系详情与筛选状态，不以两种线色作为逻辑证明。

### F：个人内容与系统反馈冲突（优先压力场景）

- 对象：沿用 `KU-035` 的正文、个人笔记及原引用；仅在独立副本构造组合，不称为默认产品状态。
- 条件与顺序：笔记待重新关联 → 存在未保存草稿 → 保存冲突；同时来源页无可靠文本，Agent 请求学生决定是否调整“已掌握”状态。
- 任务与操作：辨认每项影响对象，查看原语境与恢复／重关联／冲突处理入口；处理一项后继续阅读，检查其他内容与状态仍保留。
- 通过：笔记归属、草稿、冲突、来源限制和待决策各有具体文字与动作；不全部变成同一暖黄；系统问题不擅自改星级或掌握状态；个人内容与原引用始终可查。
- 留证：逐阶段记录提示、可操作按钮及处理结果；说明哪些故障为注入、哪些为真实回执，不能把程序模拟写成人工／硬件验收。
