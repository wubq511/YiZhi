# 公式符号批注机制核查

2026-10-27。有界官方文档与固定源码核查；未安装、运行或实测。源码沿用[正文编辑器候选核查](正文编辑器候选核查.md)的 MathLive commit `8d148b4227ca057fa1aefe89c2149cdcf0591443`，不把该快照等同全部已发布版本。

## 结论

**可以实现选单个符号批注，但不能仅凭 MathLive 的公开 selection／atomID，承诺批注在任意输入与公式改写后可靠自动跟随。** 所查公开接口没有提供可直接持久化、跨改写保持的符号出现身份或批注锚点映射合同。

首版可支持“选符号创建批注＋保存原公式与原位置／结构语境＋有明确对应时跟随”；目标被删除、合并或对应不唯一时保留原引用，标为待重新关联。应用负责身份与变更对应，MathLive 负责当前公式中的选择、取值与定位。不能把这一边界误写成“不支持符号批注”。

## 五条直接依据

1. **公开 selection 是位置集合，不是符号身份。** `Offset = number`，`Range = [Offset, Offset]`，`Selection` 是 ranges 与方向；`getValue(selection)` 可取选中片段，`getElementInfo(offset)` 可取当前位置的信息。offset 是公式编辑模型中的位置，不应当作 LaTeX 字符索引，也不是“第一个 x”的永久 ID。[当前 API](https://mathlive.io/mathfield/api/#selection)、[固定类型源码 L648–706](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/public/core-types.ts#L648-L706)、[getValue 重载 L1701–1711](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/public/mathfield-element.ts#L1701-L1711)

2. **内部 atomID 是渲染／命中映射，不能当课程永久主键。** `Atom.id` 用来关联 DOM；`bind()` 仅在 atom 尚无 id 时生成，再交给 box。因此存活 atom 可能复用 ID，不能说每次重绘都会全部换号；但 `toJson()` 不保存该 id。`Context.makeID()` 使用随机值或递增 seed，渲染的 highlighting 路径会以公式内容哈希为 seed；这不构成跨重解析、重开或改写的身份合同。[Atom 字段 L77–79、序列化 L265–307、bind L1028–1046](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/core/atom-class.ts#L265-L307)、[ID 生成 L205–218](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/core/context.ts#L205-L218)、[渲染 seed L48–65](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/editor-mathfield/render.ts#L48-L65)

3. **整体写值会走替换路径，未提供旧符号→新符号映射。** `value` 委托 `setValue()`；内部默认 `insertionMode = 'replaceAll'`，对应插入逻辑先 `deleteAtoms()`，再把输入转换成新 atoms。相同字符串有提前返回，但不同值的整体替换不能依赖旧 atom 对象继续存在。选区事件与 input 通知也不是持久批注的事务映射日志。[默认 replaceAll L1087–1104](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/editor-mathfield/mathfield-private.ts#L1087-L1104)、[删除与新建 L209–265](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/editor-mathfield/mode-editor-math.ts#L209-L265)

4. **MathJSON 提供表达式结构，不自动保留屏幕上每次符号出现的身份。** 官方 `0.111.0` changelog 明确移除 `mf.expression` 与 `getValue('math-json')`，改由 `computeEngine.parse(mf.getValue()).json` 获取；当前 interacting 指南仍举 `mf.expression`，与 changelog／固定源码不一致，应以 changelog 的迁移说明和固定源码为准。解析默认 canonical，raw 形式更接近输入，但也不是跨版本批注映射；结构等价无法唯一决定两个同名字母中哪一个承接旧批注。[官方 changelog](https://mathlive.io/mathfield/changelog/#01110-2026-09-30)、[当前 interacting 指南](https://mathlive.io/mathfield/guides/interacting/#using-a-mathfield-with-the-compute-engine)、[解析与 raw 形式](https://mathlive.io/compute-engine/guides/latex-syntax/#parsing-and-serializing-latex)

5. **公开元数据可承载应用标签，但不会替应用维护标签语义。** `ElementInfo.id` 来自 `\htmlId`／`\cssId`，`data` 来自 `\htmlData`；实现还会向祖先查找，所以返回 ID 不保证唯一对应当前单个符号。应用可给明确片段写入自己的标签作为一种锚点方案，但仍须保证唯一、保存与改写保留，并处理删除／复制／拆合；它不是自动产生的稳定 atomID。[ElementInfo L595–645](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/public/core-types.ts#L595-L645)、[getElementInfo 实现 L305–365](https://github.com/arnog/mathlive/blob/8d148b4227ca057fa1aefe89c2149cdcf0591443/src/editor-mathfield/utils.ts#L305-L365)

## 首版应由应用保留的内容与跟随规则

| 对象 | 用途与边界 |
| --- | --- |
| 稳定公式／块 ID＋公式 revision | 说明批注属于哪份公式；不能只绑定 `<math-field>` 或 DOM 节点 |
| 原公式 LaTeX＋选中片段＋当时 range | 原引用与回看依据；range 只在对应版本解释，不能直接套给新公式 |
| 原结构路径／上下文／应用片段 ID（按实现选择） | 区分重复符号及上下标、分子分母中的出现位置；结构路径随改写可能失效，不能单独承诺永久身份 |
| 变更对应与关联状态 | 已知局部编辑可按明确操作更新；Agent 整体改写需提供并核对旧→新对应，歧义时保留原关联供重定位 |

以上是应用设计推论，不是声称 MathLive 已提供完整注释系统。普通输入可以做有边界的增量跟随；若应用只能监听 input 后比较前后 LaTeX，差异匹配必须处理重复项与结构变化，不能把最接近的文本匹配当成可靠语义对应。

例如 `x+x` 改为 `2x`，左侧 x 的批注不应自动变成“所有 x”的批注；明确的转换记录可以声明合并关系，但是否转移由批注语义决定。单纯在前面增加一个未关联项，也不应因此使全部原有符号批注失效。

## 尚需验证，不能由本次源码阅读保证

- 单个字符、运算符、上下标和分式片段的选择／命中粒度，以及静态阅读态与 MathLive 编辑态的同一锚点定位。
- 局部输入、删除、Undo／Redo、整体 `setValue`、复制及关闭重开后，应用锚点保留或待重关联的行为；若采用标签包装，另测包装的序列化与编辑保留。
- 首版验收应同时覆盖“明确对应能跟随”和“歧义不误绑、原批注可找回”，不承诺任意数学等价改写的一对一符号迁移。
