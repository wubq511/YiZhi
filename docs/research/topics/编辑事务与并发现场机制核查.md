## 范围事务与历史

1. **存在保留 selection 的位置映射机制。** 从当前 `state.tr` 建立范围修改并正常应用时，`Transaction.selection` 默认将原选区映射经过新增 steps；显式 `setSelection` 会覆盖它。因此“保留”指追踪位置，不保证选中的文字或语义仍相同。[官方 API](https://prosemirror.net/docs/ref/#state.Transaction.selection)；[源码 L67–88](https://github.com/ProseMirror/prosemirror-state/blob/ffad5d9450a0b93438be53a801deee1a223a81bf/src/transaction.ts#L67-L88)。
2. **`addToHistory=false` 不等于 history 不变。** history 插件普通非入栈分支会向 `done` 和 `undone` 两支追加该事务的 maps，并映射 `prevRanges`；通常不新增事件，也不直接清空 redo，但未来撤销／重做的步骤与选区会使用这些映射。[官方 API](https://prosemirror.net/docs/ref/#history.history)；[源码 L277–297](https://github.com/ProseMirror/prosemirror-history/blob/445409bc99c88550c2312f5610829ecb25105a5f/src/history.ts#L277-L297)。
3. **历史保存逆步骤并在撤销时映射，不是恢复旧全文快照。** `addTransform` 保存每个 step 的 inverse；`popEvent` 将旧 step／selection bookmark 映射到当前文档，再尝试应用。故范围外部修改不天然要求清空同一 B 的全部 Undo。[保存 inverse](https://github.com/ProseMirror/prosemirror-history/blob/445409bc99c88550c2312f5610829ecb25105a5f/src/history.ts#L82-L108)；[撤销映射](https://github.com/ProseMirror/prosemirror-history/blob/445409bc99c88550c2312f5610829ecb25105a5f/src/history.ts#L27-L79)。
4. **结束分组与失效旧历史是两件事。** `closeHistory(tr)` 重置分组信息，保留 `done`／`undone`；后续动作形成新事件。是否在外部修改边界调用是分组策略，不是避免全文覆盖必须清栈的依据。[官方 API](https://prosemirror.net/docs/ref/#history.closeHistory)；[源码 L259–264、L363–368](https://github.com/ProseMirror/prosemirror-history/blob/445409bc99c88550c2312f5610829ecb25105a5f/src/history.ts#L259-L264)。

## IME：有条件保护，不存在本次所需的绝对保证

1. **`EditorView.composing` 只是活动 composition 状态标志。** 它没有承诺自动排队所有程序事务；`dispatch` 默认仍应用事务并更新 state／view。[官方 API](https://prosemirror.net/docs/ref/#view.EditorView.composing)；[getter](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/index.ts#L107-L110)；[dispatch 契约](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/index.ts#L487-L494)。
2. **view 确有局部 composition DOM 保护。** 更新子节点时识别 composition，尝试复用相关节点并保护文本 DOM；但要求选区及 focused text node 仍能定位于对应节点，文本在新内容中找不到时该保护返回 `null`。[viewdesc.ts L767–851](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/viewdesc.ts#L767-L851)。
3. **源码存在主动清除 composition 的更新路径。** `updateStateInner` 在 `state.storedMarks && composing` 时调用 `clearComposition`，并有文档视图无法复用时销毁重建的路径。因此不能从 mapping 或 composing 标志推出“程序事务一定不中断中文 composition”。[index.ts L153–204](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/index.ts#L153-L204)；[clearComposition](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/input.ts#L520-L525)。
4. **架构推论：** 保护活动选区及 composition 所在内容／必要祖先结构，冲突更新暂缓后基于最新 state 重核；compositionend 后仍有 pending DOM changes 的 flush，不能把事件到达直接当作全部输入已进入 state。其他独立内容可争取继续更新，但具体 Electron／IME／插件组合的不中断效果仍未被本次静态核查验证。[compositionend 路径](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/input.ts#L502-L512)；[局部保护条件](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/viewdesc.ts#L815-L829)。

## 不能从该机制顺带推出的能力

- **位置映射 ≠ 语义冲突整合。** `StepMap` 处理范围／偏置／删除，不能判断讲解是否仍正确或是否尊重学生新意图；官方 collab 也显式维护版本、未确认步骤及 rebase，并将接收事务标为 `addToHistory=false`，而非仅加一个标志就完成并发整合。本次不据此选定 collab。[StepMap](https://github.com/ProseMirror/prosemirror-transform/blob/662b7a937bafde19b7e2a83241dbc8888e257c89/src/map.ts#L93-L115)；[collab.receiveTransaction](https://github.com/ProseMirror/prosemirror-collab/blob/7736c6c9ad4407af2678112a1cad82c1d3c53dcf/src/collab.ts#L116-L150)。
- **外部不入即时 Undo ≠ 正式 Agent 任务可选择性撤回。** history 保存的是编辑器局部逆步骤；任务边界、版本依据及保留后续学生内容的正式撤回仍属应用历史协议，不能用该 metadata 替代。[history 保存方式](https://github.com/ProseMirror/prosemirror-history/blob/445409bc99c88550c2312f5610829ecb25105a5f/src/history.ts#L82-L108)；[metadata 的限定作用](https://prosemirror.net/docs/ref/#history.history)。
- **不自动解决视口、批注或持久化。** view 有 preserve／reset／scroll-to-selection 分支，但不是画板相机稳定保证；批注须另行维护锚点，不能把 selection mapping 当任意批注恢复；SQLite 提交、自动保存确认与失败恢复也不是 transaction 的内建落盘行为。[view 滚动分支](https://github.com/ProseMirror/prosemirror-view/blob/ca4c78e9b56f1b164c0b3758b59d8748f11b7534/src/index.ts#L178-L182)；[SelectionBookmark 范围](https://prosemirror.net/docs/ref/#state.SelectionBookmark)；[transaction 契约](https://prosemirror.net/docs/ref/#state.Transaction)。
- **未验证自定义 NodeViews／MathLive。** NodeView 自管 DOM／selection／事件有独立接口，普通正文映射和 composition 路径的证据不能直接外推至公式内部；本次未读接入实现，也不假定它们已集成。[官方 NodeView 接口](https://prosemirror.net/docs/ref/#view.NodeView)。
