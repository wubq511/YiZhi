# 数字逻辑期中复习：现成学习与知识图谱产品调研

核查日期：2026-10-24。对象：NotebookLM Mind Maps、Obsidian Canvas / Graph、Heptabase、TheBrain，以及补充候选 draw.io。目标是从 PDF 课件整理知识点，表达前置依赖、概念关系和解题流程。

本报告依据公开官方帮助、产品页、格式规范和许可证；未安装、登录或用本课程 PDF 实测。“适合”“优先”属于基于功能证据的选型判断，不是效果测评。未检索 X，未制作 demo。访问 NotebookLM 原帮助入口时，官方已重定向到名称为 **Gemini Notebook** 的帮助中心；本文沿用用户指定的 NotebookLM 名称，链接采用本次实际读取的官方页面。[官方帮助入口](https://support.google.com/notebooklm/)

**结论：没有证据表明其中任何产品能直接、可靠地把数字逻辑课件转成经过验证的教学前置依赖图。** NotebookLM 适合快速抽取与导航；Heptabase 提供最接近“PDF → 带引用概念卡 → 可编辑白板”的一体化工作流；Obsidian Canvas 和 draw.io 适合人工明确关系；TheBrain 适合长期积累带类型的知识网络。这里的“没有证据”限定于本次查阅的官方功能文档，不等于断言产品无法实现任何相关工作流。[Mind Maps][N1]、[Heptabase PDF 工作流][H1]、[Canvas][O1]、[draw.io 依赖图][D1]、[TheBrain 关系类型][T1]

## 先区分要表达的四种结构

下列数字逻辑例子只用于说明选型标准，不代表已经从课件抽取或确认的教学顺序。

| 结构 | 一条边实际表达什么 | 对本场景的作用与边界 |
| --- | --- | --- |
| 目录树 / 主题导图 | “属于某主题”“是它的子主题”，通常从中心主题分支 | 可用来浏览“组合逻辑 → 加法器”等范围；不能由上下层级直接推出“必须先学”。NotebookLM 官方将 Mind Maps 定义为主题与相关想法的分支图。[Mind Maps][N1] |
| 显式语义关系 / 前置依赖图 | 明确写出“是前置”“等价于”“实现”“用于化简”等关系，允许跨章节、多入边 | 必须同时保留方向、关系名称和证据。Canvas 有可标注的有向边；TheBrain 有 Link Types；draw.io 可绘制依赖图。但能够画边，不等于能判断依赖是否成立。[Canvas][O1]、[TheBrain][T1]、[依赖图][D1] |
| 双链 / 引用关系图 | A 笔记链接到 B 笔记；反向链接让 B 能找到 A | Obsidian Graph 的线代表内部链接，箭头只表示引用方向。**它也不是自动统计同页词语共现的图**；共同标签、引用或相关性均不自动等于前置依赖。[Graph view][O2] |
| 解题流程图 | 步骤先后、条件分支、循环或检查，例如“列真值表 → 化简 → 实现 → 校验” | 需要稳定布局、步骤说明和分支标签。draw.io 是直接匹配的绘图工具；Canvas 可用带标签连线组织步骤。流程边应与“知识前置”边区分。[连接线][D2]、[Canvas][O1] |

## 能力对比：可直接纳入总表

“支持”表示官方有明确文档；“未确认”表示本次来源没有足够证据，不应填成已支持，也不应扩大成绝对不可能。

| 产品 | PDF → 知识点与来源追溯 | 图的真实性质 | 前置依赖与解题流程 | 本场景评判 |
| --- | --- | --- | --- | --- |
| **NotebookLM Mind Maps** | 支持 PDF 输入、来源摘要与带引用问答；Google 另说明 PDF 支持图像和图表内容。尚无本课程电路图、公式准确率证据。[来源][N2]、[引用问答][N3]、[PDF 图像说明][N4] | 自动生成可展开、折叠的主题分支图；点节点可继续提问。[Mind Maps][N1] | 未见官方确认自定义关系类型、任意跨分支连边、逐边编辑或前置依赖校验。适合知识范围导航，不能直接作为已验证依赖图。[功能范围][N1] | **快速整理课件的优先候选**；最终依赖关系与题型流程宜另行整理。此判断基于其自动摘要、问答和分支图能力。[N1 功能][N1]、[N3 功能][N3] |
| **Obsidian Canvas / Graph** | Canvas 可嵌入 PDF，与 Markdown 笔记并排组织；本次核心功能文档未确认自动从 PDF 抽概念。AI、OCR 扩展不能算作这两项核心功能已经具备。[Canvas][O1] | **Canvas：人工组织的空间概念图。Graph：笔记链接网络。** 二者不应合并成一个“自动知识图谱”能力。[Canvas][O1]、[Graph][O2] | Canvas 支持连线标签、颜色、单向/双向/无方向，足以人工表示关系与步骤；Graph 箭头没有“前置”类型语义。[Canvas][O1]、[Graph][O2] | **重视长期保存、笔记与图联动时优先**；需要先准备概念笔记，再人工或借外部工具建立关系。[本地文件][O3]、[Canvas 开放格式][O4] |
| **Heptabase** | 支持 PDF 阅读、文本/区域标注、Highlight cards、OCR 解析；AI 可按页范围生成概念卡，`Break down book` 可生成带引用的白板内容。[PDF 标注][H2]、[PDF AI 工作流][H1]、[解析说明][H3] | 可复用概念卡、白板、分组、双链与思维导图并存；白板箭头和连接说明能承载人工关系，不限于目录树。[AI 与白板][H4]、[连接说明示例][H5] | 可以整理跨概念关系、建立带说明的连接；AI 也能创建/更新白板连接。**未确认它会区分并验证“教学前置”“逻辑等价”和“相关”。**[AI 文档][H4]、[2026 更新记录][H6] | **愿意付订阅费时最值得验证的一体化候选**。优势是阅读、引用、卡片与白板接近同一流程；不能再把它概括为“只能手工摘录”。[PDF AI 工作流][H1] |
| **TheBrain 15** | 支持文件附件；当前 Cerebro 官方说明可总结附件、创建 Thoughts / notes / structures 并建议连接。**PDF 逐页引用、扫描课件 OCR、公式/电路图识别质量未在所读功能文档中确认。**[产品页][T2]、[v15 说明][T3] | 原生网络包含 parent、child、jump 关系，并支持 Thought Types / Link Types；不是只有单根树，也不是只画双链。[官方教程][T1] | Link Types 可明确关系含义，适合人工约定“前置”“应用”等类型；流程也能映射为节点连接，但教学依赖推断与流程执行校验未确认。[关系教程][T1] | **长期跨课程知识网络候选**。若近期只需几张期中复习图，已有来源可追溯的白板或直接绘图工具路径更短；这是工作流判断，未测量学习成本。[T1 功能][T1]、[T3 功能][T3] |
| **draw.io / diagrams.net** | 官方支持从文本、Mermaid、CSV 等构造图；本次未找到普通 PDF 课件自动解析、逐条证据引用的完整内置流程。不要将“导入带图数据的 PDF”当作“读懂课件”。[文本生成依赖图][D1]、[可编辑文件][D3] | 自由概念图、依赖图、流程图；支持跨分支连线、箭头和标签。[依赖图][D1]、[连接线][D2] | **适合明确画出依赖与解题步骤**；也可由已整理的关系表生成初稿。语义和正确性由内容整理者负责。[依赖图创建方法][D1] | **短期复习、零订阅、重点在图的表达时优先**。作为第 5 个候选，是为补足流程表达与可迁移性，不是替代 PDF 阅读助手。[免费与本地存储][D4]、[导出][D5] |

## 影响选型的具体限制

**NotebookLM：先把主题导图和知识关系表分开。** 官方文档确认的导图操作是生成、缩放、折叠、点击追问、下载和分享；不能因为页面写“connect the dots”，就推定其支持任意关系类型。更稳妥的复习产物是概念列表及带来源的关系候选，再放进 Canvas / draw.io，或保留为可导出的 Data Table。这个组合是建议工作流，尚未验证自动迁移。官方当前还注明移动 App 不支持 Mind Maps，应按网页版能力评估。[Mind Maps][N1]、[Data Tables][N8]

**Obsidian：Canvas 和 Graph 不互相替代。** Canvas 的纯文本卡片不进入 Backlinks；若需要笔记引用网络，应转成文件卡片。公开 `.canvas` 的边含 `fromNode`、`toNode`、端点箭头和 `label`，因此很适合保存明确关系；该规范本身未定义“教学前置”的推理或约束。对本场景，建议以 Canvas 为复习主图，Graph 作为补充浏览。[卡片与双链][O1]、[边结构][O8]

**Heptabase：解析、摘录、AI 建卡是三个不同动作。** OCR 解析把 PDF 转成 AI 能读的内容，并不自动创建 Highlight cards；选中原文或区域才形成阅读标注。AI 按页生成概念卡和带引用白板是另一条流程，会涉及 AI 用量。官方建议长文先处理一章或约 20 页，并明确这只是起始建议，不是固定页数上限；没有保证一次处理整本书成功。[解析与额度][H3]、[PDF 标注][H2]、[长 PDF 指南][H1]

**Heptabase 的“免费”需限定使用方式。** 官方目前仅向付费用户邀请的协作者提供受限免费方案，缺少个人白板/卡库、Highlights 和 AI，不能视为个人完整复习方案。个人订阅结束后仍可长期访问和导出已有内容，继续创建或编辑则要续订。[免费方案][H9]、[到期后访问][H10]

**TheBrain：不要沿用旧版收费印象，也不要把 AI 宣传视为 PDF 实测。** 当前 v15 产品页、比较表和 EULA 均支持“完整应用免费”的结论；搜索中仍能遇到旧版 Pro / Pro Combo 页面，本报告以当前资料为准。Cerebro 可以总结附件、建议关系是官方功能声明，但这不足以证明它能准确从电路图、卡诺图和时序图抽取教学依赖。[v15][T3]、[当前方案][T4]、[EULA][T5]

**draw.io：保留原始图文件比只导出 PDF 更重要。** PDF 携带可编辑图数据取决于导出方式；官方说明桌面应用及无导出服务器的自托管实例走打印流程，不提供该嵌入选项，Safari 也可能不支持。最直接的保存策略是 `.drawio` 作为编辑原件，SVG / PDF 作为阅读件。[PDF 导出限制][D6]、[格式说明][D5]

## 对数字逻辑期中复习的选型建议

1. **已有 Obsidian，或希望复习材料长期保存：优先 Obsidian Canvas。** 用笔记卡保存定义、例题和来源，再在边上明确写“前置”“等价”“实现”“步骤”。PDF 自动抽取由 NotebookLM 等资料助手辅助；不要把 Graph 自动生成的引用网当成最终依赖图。[Canvas][O1]、[引用图定义][O2]、[NotebookLM 引用][N3]
2. **希望尽量在一个产品内完成阅读、摘录和建图，并能接受订阅：优先验证 Heptabase。** 它有直接的带引用 PDF → 白板文档证据；真正需要后续 demo 验证的是数字逻辑公式、图片中的电路、页码定位和关系准确性，而不是它是否具备基本白板或 AI 建卡功能。[PDF AI 指南][H1]、[标注功能][H2]
3. **只需要本次期中的若干依赖图与解题流程：draw.io 更直接。** 先整理知识点和关系，再画或导入图；无需为了几张复习图先构建完整笔记系统。这个判断基于免费免账号、显式依赖绘图与文件保存能力，不代表它具有 PDF 理解能力。[官网][D4]、[依赖图教程][D1]
4. **TheBrain 留作长期网络型知识库候选。** 它的关系类型值得比较，当前免费政策也降低了门槛；但现有官方资料尚不足以把它排在 Heptabase / NotebookLM 前面承担本课程 PDF 的证据化抽取。[关系类型][T1]、[v15 AI][T3]、[定价][T4]

后续 demo 的核心验收对象应是“关系及其证据”：同一个概念能否有多个前置、每条边能否说清关系种类、能否回到 PDF 原文核查、导出后是否仍能编辑节点和边。**本报告没有为任何产品给出数字逻辑内容准确性或学习效果分数。**
