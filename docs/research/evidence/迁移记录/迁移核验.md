## 文件保留与字节核对

- 迁移前先记录全部 288 个原文件的路径、字节数、SHA-256 及旧→新映射，之后才移动目录。迁移后逐一核对：288/288 原文件存在，旧根目录已移走，没有删除原资料。
- 278 个原文件字节完全不变；10 个原文件只修引用路径。248 个受保护文件（图片、SVG、字体、240 个 Excalidraw runtime 文件及 `.DS_Store`，去重计数）全部 SHA-256 一致。
- `mux-skill-comparison` 原有内部相对路径结构整体保留，跨到 Archify、Diagram Design 的展示链接按新层级更新。
- 总览保留 24 个工具小节、23 个图片引用；5 张本地图片使用迁移后的绝对路径，18 张远程图片继续使用原 URL。远程来源没有联网重验。
- `visual-explainer-mux.src.html` 原本引用缺失的 `kit.css`。新添同名文件，内容逐字提取自既有正式 HTML 的 `<style data-ve-kit>`，未重新生成页面、图形或算法，原运行依赖字节不变。

完整文件与 SHA 对照见[迁移前清单与路径映射](迁移前清单与路径映射.json)和[迁移后清单](迁移后清单.json)。后者记录迁移交接时的快照；主线程随后可能更新总览及设计内容，以当时的交接 SHA 为准。

## 引用核验范围

逐条检查 Markdown 行内与引用式本地链接、HTML 标签中的展示链接和资源、动态演示入口、CSS `url()`、JSON 当前产物路径、Canvas 文件引用、Excalidraw 的 230 个字体 URI 及运行资源目录。课程 PDF 链接按新文档层级重新计算，保留文件名中的字面 `+`。现有 Canvas 没有文件节点或本地文件引用，JSON 语法与原内容保留。

核验通过：377 处本地引用均可解析，断链 0 处；14 个 JSON / Canvas / Excalidraw 数据文件解析通过。逐项结果与计数见[链接核验](链接核验.json)。所有可用本地引用均按实际目标文件/目录核验，不以替换旧根前缀代替检查。远程图片和外部官网链接只保持原引用，未访问网络；未重跑原图算法或旧测试。
