## 工作范围与并行

所有学生手动操作在本票完成：可视化文字/公式编辑、基础形状和箭头、对象移动与尺寸、笔记锚点和明确关系建立。共用 #01 保存与 #03 的任务/撤回合同，不各自实现一套存储或历史。

#01 基础读写通过后开始，与 #02/#03 并行；早期在当前样本和稳定正文合同上验证，后续接完整正文与实际 Agent 事件。

**修改所有权：** 文字/公式编辑、片段笔记、图形标注、对象变换及明确知识关系建立。公共入口与权威文件由集成者串行合入，见 [并行实施规则](../../implementation/03-并行实施与验证.md)。

## Acceptance criteria

- [x] 文字、公式和笔记有明确编辑入口，工具栏按需展开；公式通过点选符号和结构操作，学生无需先输入 LaTeX 源码。
- [x] 编辑保持稳定块 ID、原文引用及知识主位置，通过统一命令提交；保存/冲突反馈真实，刷新和服务重启内容一致。
- [x] 基础手动撤回/重做形成合理编辑组，不与导航返回混淆；学生后来改动同一片段时不能被陈旧结果静默覆盖。
- [x] 提供直线、波浪线、荧光笔、基础形状和箭头，并支持移动/调整对象大小；高亮不遮文字或数学符号，手绘笔触、端正排版与内容配色同时保留。
- [x] 普通手画箭头只作为个人标注，不改变正式关系或前置结果；明确选择建立知识关系并指定类型、价值、方向与来源后才提交。
- [x] 正式关系沿用知识规则和 AND/OR 语义，缺失依据、非法/退休端点和非法循环等明确拒绝；有效变化在图、查询、保存及撤回后一致。
- [x] 对象笔记和片段笔记保存独立身份、当时修订、原引用与定位；图形标注沿用相同的跟随与保留规则。
- [x] 内容移动时跟随，改写保留旧语境；拆合只在对应明确时重新关联，不确定时保留并提示，不向多个新对象自动复制。
- [x] 原对象删除/退休后笔记与图形仍可找到并重新关联；撤回 Agent 修改也不能丢掉后来个人内容。
- [x] 缩放/平移、编辑选取与拖动图形不互相抢手势；位置/尺寸写独立布局，显示深度切换不丢内容，原位展开与返回继续可用。
- [x] 绑定的公式、图和交互按同一语义配置更新；无法转换为受支持语义时保留编辑并明确探索结果需核对，不继续把旧计算称作一致。
- [x] 与 #02 的真实正文块联调，并与 #03 实际任务验证运行中编辑、冲突说明、撤回保留笔记/图形；完成保存重开、关联失效和恢复路径。
