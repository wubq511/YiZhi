## 工作范围与并行

同一工作线贯通执行器、侧栏、对话、修改队列、选择性撤回、并发与失败恢复；描述性检索、资料更新意图和添加学习交互复用同一 Agent 能力，不再拆成独立票。

**修改所有权：** 真实问答、学习对话、Agent 修改、同时修改、撤回与任务恢复。公共入口与权威文件由集成者串行合入，见 [并行实施规则](../../implementation/03-并行实施与验证.md)。

## Acceptance criteria

- [x] 首先完成选中对象→真实流式问答→保存对话→重开的闭环；使用独立 app-server 会话并记录当前版本，不依赖接管当前 Codex 桌面聊天，也不重复把旧探针当新应用验收。
- [x] 提交时冻结对象、片段、版本、出处和意图，后续浏览不换任务目标；普通回答先进入侧栏，明确要求添加或一键加入才写画板。
- [x] 侧栏可收合调宽，保存多段对话并默认继续最近一段；切换对话不回退画板，完成只提示与提供前往入口，不强制跳走视口。
- [x] 接入 #02 的原文选段和版本引用；画板、原文、Agent 同时使用并可调整空间，保留视口、页码、草稿与选择，回答区分原文依据和补充解释。
- [x] 明确的改写、纠错、补充、扩展、整理和精简直接通过统一命令生效并保存；修正直接受影响的主内容，不把必要纠错放附注，不自动改写个人笔记。
- [x] 同课程跨对话修改默认排队，开始时读取原目标的最新内容；问答和阅读可继续，目标失效时说明原因。
- [x] 学生在执行期间编辑目标，立即把位置和最新内容通知 Agent；最终仍检查修订，保留学生最新修改。通知失败或晚到不能虚报已经处理。
- [x] 可兼容修改整合后也明确说明发生同时修改、涉及哪里和如何处理；无法兼容时只询问冲突部分，不禁用学生编辑来规避。
- [x] 按任务/操作选择性撤回，并保留后来笔记与标注；同一片段有后续手工改动时核对冲突，不恢复整份旧快照覆盖它。
- [x] 整幅版本回退有独立入口并保存当前恢复点；产生新的课程代际/修订，事件序号、去重记录与执行事实不回退，恢复前任务的迟到提交不得重新通过检查。
- [x] 停止保留已提交结果、阻止后续新提交；重连/重启先核对任务实际状态，未完成任务由学生点击继续，再依据最新内容补做，不静默重跑或重复应用。
- [x] 已掌握内容的重要结论/方法实质变化后，询问学生是否调整状态；正文照常生效，未确认保留原状态，纯措辞和排版不触发提示。
- [x] 描述性查询只返回课程里真实存在、可定位的命中；新增解释留在回答，模型不可用仍保留本地关键词搜索。
- [x] 新增/替换资料先保留版本并提示是否更新；暂不更新不改变画板和旧引用，回答使用新版时说明版本与差异；选择更新才发起任务，结果直接生效且可撤回。
- [x] 能按明确请求添加受支持的 MUX/译码器/卡诺图交互，图、公式、控制和输出一致且可保存；不支持能力如实说明，不以截图或空组件充数。
- [x] CLI/模型不可用、实际执行权限请求、失败、保存失败与中断分别反馈；真实成功路径配合可控执行器覆盖重复/乱序事件、执行中编辑、写后断线及恢复。
- [x] 与 #04 的样本并发、撤回保留个人内容，以及来源/搜索/重开已通过；02 全部正文交付后，完成完整课程与 Agent/标注一起迁移的最后组合验收。

## 验证与完成

先真实问答，再真实修改/运行中通知/停止；用执行器端口替身定向注入冲突、断线和迟到结果；最终浏览器串起修改→笔记→撤回→重开，不机械重复无关模型调用。

本票可以跨多个上下文持续推进，相关工作不再拆成独立小票。只勾选真实完成的验收项，记录运行命令、浏览器路径和未验证部分；四票共用的最终学习流程按实施规则联调，不另开一张总验收票。
