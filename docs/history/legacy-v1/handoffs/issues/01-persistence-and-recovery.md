## 工作范围与并行

本票负责持久化和阅读基础，包含本地启动、稳定导航、对象笔记、状态、阅读上下文与可迁移课程文件。Agent 任务的继续/去重归 #03；公式和图形编辑归 #04，均复用本票的提交与保存接口。

可与 #02 同时开始。#01 的基础保存验收通过后，#03 和 #04 可领取；不需要先等 #02 的 84 单元全部写完。

**修改所有权：** 本地运行、课程存储、阅读画板与公共读写接口。公共入口与权威文件由集成者串行合入，见 [并行实施规则](../../implementation/03-并行实施与验证.md)。

## Acceptance criteria

- [x] 启动入口能启动本地服务并打开独立网页，支持原生浏览器全屏；端口占用、已有实例和保存失败给出实际反馈。
- [x] 先只读复用当前四个样本及正式知识身份，不另建可独立编辑的课程内容；#02 的 reading 可用后切换同一读取适配器，原笔记和状态仍绑定同一 KU。
- [x] 打开即进入同一课程画板，目录与小地图默认展开且可收合；进入主题先到第一个 B，缩远先经过可停留的 B 全览再到 A。
- [x] 保留已认可的顺序、原位展开、局部让位、答案揭示、关系显示、知识引用与返回；主/辅助不误作前置，AND/OR 路线与稳定位置保留。
- [x] 滚轮缩放/触控板平移模式明确，指针锚定、拖动与连续输入顺手；不在每个输入事件重建整张图，保留手绘笔触、端正排版与内容配色。
- [x] 对象笔记可新增、修改并自动保存；B 的待复习/薄弱/已掌握互斥、默认待复习，A 仅汇总，可筛选定位，与重要性星级区分。
- [x] 课程文件保存正文引用、布局、个人内容和阅读上下文；视口、展开、答案、探索输入、返回栈、面板状态等重新打开后恢复，浏览器缓存不是唯一保存。
- [x] 实现共享 CourseService 的查询、命令、对象修订、幂等操作和持久化事件；同一课程只有一个写入者，后续模块通过公共入口扩展。
- [x] 保存成功只在落盘后确认；重复提交不重复生效，陈旧版本不覆盖新内容。写入中断恢复完整的提交前或提交后状态，不留下半份 JSON。
- [x] 关闭浏览器和服务后重启恢复；复制课程到不同路径仍能读取已保存内容和本地资源，离线可复习。本票以当前样本、笔记、状态和阅读上下文完成基础验收；后续对话、标注和任务数据由 #03/#04 接入后使用同一保存机制并验收，不反过来阻塞本票完成。
- [x] 记录实际运行命令、HTTP 映射、模块注册方式和读写合同；基础通过后向 #03/#04 交接，不等待全部课程正文完成。
