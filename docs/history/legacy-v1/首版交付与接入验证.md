## 阅读体验检查

2026-10-25，Robert 在真实内容原型试用中补充以下长期要求，详见 [设计记录](../复习系统设计讨论.md#reading-experience)。这些是正式应用和后续内容增补的验收条件；此前原型的“可操作”记录不能替代这些体验检查。

| 检查 | 通过条件 |
| --- | --- |
| 布局与顺序 | 仅按从左到右、从上到下扫读即可辨认合理顺序；前置先于使用，并列分支没有被画成必修链；目录与画板次序一致 |
| 三级缩放 | 从主题进入第一个 B；逐步缩远时，能完整看到主题内全部 B 及关系，并继续停留或选择其他 B；再缩远才出现 A。分别检查鼠标滚轮、捏合和缩放按钮 |
| 讲解用语 | 连续读完整单元，无生硬口号、未定义符号或断裂语句；关键条件在使用前交代，公式与原资料一致 |
| 视线连续性 | 图与解释、控制与结果相邻；例题顺着步骤读完，无需反复跨栏或到其他卡片寻找当前步骤所需信息 |
| 操作响应 | 指针锚点稳定，连续滚动与拖动及时响应，结束时位置正确；切层不闪回、不提前隐藏 B，不在每个输入事件中重建整张图 |
| 状态与视觉延续 | 展开、答案、笔记、标记和返回位置保留；导航和缩放不重排知识位置；手绘笔触、端正排版与内容配色同时保留 |

当前原型已按上述要求修订，并完成 Chrome 中的三级缩放、阅读顺序、锚点、拖动、平移模式和展开返回检查，详见 [原型验证记录](../../../experiments/content-depth-prototype/README.md)。物理触控板捏合、中键硬件手感和 Safari 原生手势尚未单独验收，正式应用仍须继续执行这些检查。
