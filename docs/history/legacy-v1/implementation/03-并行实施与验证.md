## 领取与所有权

1. 选择前置已完成且未被领取的主票。#01 基础已完成；#02 并行进行，#03/#04 的基础前置已满足。进展以票内 Status 为准。
2. 在 `.scratch/review-board-v1/claims/` 下为两位票号原子创建目录，并记录 agent/会话、时间与工作副本，再更新票内 Owner/Status。创建失败说明已被领取，核对持有人后处理，不覆盖他人的 claim。
3. 每票一位主负责人，可在票内安排适合的 subagents。章节分工与内部验收不另生成子票。模型按难度选择：并发/恢复/选择性撤回用较强推理；基础资料核对可用较轻模型，公式、电路和跨页题解必须可靠推理且能实际看图。
4. 票内 Status 是任务进展的权威记录，可用 ready-for-agent、in-progress、blocked、review、done；plan.json 只记录四票依赖、范围与需求映射，不重复保存实时状态。
5. 只有真实合入、读回并通过对应验收后才勾选完成项。整票的全部要求满足后再标 done；中途已经可用的接口先交接，不因整票还在进行而扣住成果。
6. 交付记录包含改动位置、实际命令、浏览器行为、已交接接口和未验证部分。释放本人 claim，清理不再需要的临时文件；原件、正式资源和验收依据保留。遗留 claim 先核对实际任务状态，不仅凭时间抢占。

领取与集成是 agent 协作，不是新增用户审批。产品规则已经确认，可逆实现选择按合同推进；要改变已确认体验或范围时才具体说明影响。

#01 为尽快交付保存，可只读复用已有样本，不复制出新的可编辑正文源。#02 负责把包括四个样本在内的全部 84 单元迁入唯一权威 reading；切换适配器保持同一单元身份、个人笔记和阅读状态。

## 正文工作线的章节分工

#02 负责人在票内维护 20 个主题完成清单和当前内容负责者；可以安排多位内容作者，但每个单元同一时刻只有一位作者。正文、图示、题解和校验作为同一个章节工作完成，不再为其分别编号。

临时工作包放在 `.scratch/review-board-v1/work/02/<章节或批次>/`。包是待导入提案，包含 reading、必要题目增补、本地资源、来源定位、掌握目标覆盖和原页核对记录。作者只在独立课程副本导入/构建/预览；原件共用只读，生成资源使用本批命名空间。

同一题目或来源的相同增补只存一次，冲突交本票集成者核对原文，不按后到覆盖。正式课程只读权威数据，不长期以内容包作为另一份正文库。每批集成后读回、检查实际呈现，再更新主题完成项。

使用现有 `MIDTERM_MAP_FILE`、`MIDTERM_LAYOUT_FILE`、`MIDTERM_OUTPUT_DIR` 或正式应用的等价课程根配置隔离副本。新内容需要的公共渲染能力由 #02 统一扩展，不在章节里嵌一套独立页面应用。

## 验证方式

主要从真实本地 CourseService 和浏览器使用路径验收；只在执行器端口使用可控替身注入竞态。保存恢复必须真正退出服务再重开，不能只刷新内存或确认 localStorage 有值。测试与当前改动相称，已通过且未变化的场景不机械重复。

从项目根运行。知识 CLI 需要完整 JSON，直接运行 Python；对可稳定代理的命令优先 RTK，缺排障细节时立即回退。

```bash
python3 期中/工具/知识地图.py get KU-055
python3 期中/工具/知识地图.py questions KU-055 --role direct
python3 期中/工具/知识地图.py related KU-044 --depth -1
python3 期中/工具/知识地图.py graph --view all
```

修改知识或布局后按 Skill 校验和重建：

```bash
python3 期中/工具/知识地图.py check --source-only
python3 期中/工具/知识地图.py build
python3 期中/工具/知识地图.py check
python3 -m unittest discover -s 期中/工具 -p 'test_*.py'
```

教材首次使用或资料变化后先校验，再按 Skill 检索、阅读全文范围并实际看图，不重新 OCR 整本：

```bash
python3 教材/数字设计和计算机体系结构-检索版/工具/教材.py verify
```

01 的启动及专项测试命令已列在 [应用说明](../../../../legacy/review-board/README.md)；正文工具由 02 在实际建立后补充。内容正文以学习目标和原页验收，不为文案增加镜像测试；硬件手势未实测则如实记录，不能以程序性滚轮等同所有手感通过。

## 四票共同的收尾检查

不单开总验收票。各主负责人把有关结果写回自己的票，最后在同一正式课程执行：

- 正式 20 主题、84 初始有效单元均可完整阅读，例题/练习与来源齐备，五项阅读和三项视觉要求持续满足。
- 读主题 → 展开材料 → 写对象/片段笔记 → 标状态 → 原文选段问答 → 请求真实修改 → 学生同时编辑 → 撤回保留后来笔记/图形 → 关闭重开。
- 原文版本、关键词/描述搜索、个人箭头/正式关系和状态调整行为符合合同；跨面板和引用返回不丢上下文。
- 任务中断/恢复去重，运行中历史回退后的迟到提交被拒绝；课程复制到新路径后可离线继续，旧依据与个人内容仍可找到。

初始覆盖按 84 单元检查；之后学生明确新增、拆分或合并按稳定身份与退休规则处理，不用固定计数阻止合法编辑。四票完成并通过组合路径后才标正式首版交付。
