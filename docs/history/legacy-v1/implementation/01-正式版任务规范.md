# 本地复习画板首版：任务规范

日期：2026-10-25。产品要求来自已确认的设计讨论和阅读原型反馈；本文件把它们收敛为可执行规格。按 Robert 的最新要求，任务仅分为四张主票：保存恢复、课程正文、真实 Agent、编辑标注；相关工作留在同票验收项中，不再细拆。01 的本地阅读与文件保存基础已实现，完整首版仍按四票共同验收。拆分入口见 [任务总表](../handoffs/README.md)。

## Problem Statement

Robert 需要在一张课程画板中完成数字逻辑期中复习，顺着知识关系阅读解释、图示、方法、例题与练习，并随时记下理解、核对原文、向 Agent 提问或要求修改。现在已有经过整理的知识地图和可操作的阅读样本，但完整正文、课程文件保存、正式编辑、真实 Agent 和失败恢复尚未贯通。

现有知识索引包含 20 个主题、84 个有效知识单元、121 个题目实体、202 条题目映射和 43 条已审核关系。它不等于已准备好完整复习正文。原型的 4 个正文样本也不能代替全量内容；页面内暂存不能代替可备份、迁移的课程文件夹。

## Solution

交付一个电脑端本地网页和启动入口。打开即进入同一张课程画板，以主题 A、单元 B 及单元内部材料组织完整复习。默认展开目录和小地图；进入主题先读第一个 B，缩远先经过主题内 B 全览，再到 A 概览。正常阅读所需材料提前备齐，原文回查和 Agent 用于核对、解惑与进一步修改。

课程文件夹保存权威知识、独立布局、复习资料版本、个人笔记、复习状态、对话及阅读上下文。文字和可视化公式可以手动修改；Agent 回答普通提问，明确的修改请求则直接生效并可撤回。任务目标、同时修改、停止、撤回与恢复遵循统一规则。

交付分为三个检查点，不把中途可用误称为首版完成：

1. **最小可持续使用**：能读真实单元、写对象笔记、标复习状态，关闭本地服务再打开仍能继续。
2. **四条工作线并行推进**：保存恢复与正文准备先并行；基础读写可用后，真实 Agent 和编辑标注接入。章节是正文票内部的完成清单，不另建章节或单元子票；每条工作线可连续跨上下文推进。
3. **首版验收**：全部 84 单元的完整阅读与本规格要求的工作流通过集成验收。原计划使用日和考试时间是用户背景，不是尚未验证的交付承诺。

## User Stories

以下以 `US-01` 等编号追踪验收和票据。每条描述学生可观察到的结果。

1. 作为学生，我希望通过一个入口启动服务并打开画板，以便直接开始复习。
2. 作为学生，我希望打开后就是课程画板，目录和小地图默认展开且可收合，以便在连续空间中定位。
3. 作为学生，我希望每门课程只有一张持续扩展的画板，以便后续学习接着已有内容积累。
4. 作为学生，我希望资料、画板、笔记和对话保存在课程文件夹，以便整体备份、迁移和重新打开。
5. 作为学生，我希望断网仍能阅读已保存内容，以便模型不可用时继续复习。
6. 作为学生，我希望全部正式知识单元已具备必要解释、图示、方法、推导与题解，以便正常复习不依赖临时生成。
7. 作为学生，我希望概念、方法和器件分别呈现理解或使用所需的核心，以便不被统一模板遗漏条件或填充无关内容。
8. 作为学生，我希望解释使用连贯、自然的中文，先交代符号、术语和适用条件，以便顺着读懂。
9. 作为学生，我希望主题与单元按知识和阅读顺序从左到右、从上到下排列，以便先理解基础再使用，并辨认并列分支。
10. 作为学生，我希望进入主题时先看到第一个单元，以便知道从哪里开始读。
11. 作为学生，我希望缩远先看到该主题所有 B 及关系，继续缩远才看到 A，以便了解主题内部结构后再离开。
12. 作为学生，我希望平移、缩放和导航不随意重排知识位置，以便保持空间记忆。
13. 作为学生，我希望图、公式、讲解、控制和输出靠近对应内容，以便减少跨栏或跨卡寻找条件。
14. 作为学生，我希望滚轮、捏合、指针锚定与拖动及时稳定，以便自然浏览大画板。
15. 作为学生，我希望能明确选择滚轮缩放或触控板平移模式，以便输入行为可预测。
16. 作为学生，我希望长材料在所属单元原位展开、附近局部让位，收起后恢复，以便保持阅读位置。
17. 作为学生，我希望例题展开后直接看到完整讲解，以便连续学习解法。
18. 作为学生，我希望练习先显示题目，提示和答案由自己揭示，以便先自行作答。
19. 作为学生，我希望缩远、返回、关闭再打开后保留展开和答案状态，以便继续上次进度。
20. 作为学生，我希望完整知识只在主位置维护，其他地方通过知识引用跳转且能返回，以便避免不同副本互相矛盾。
21. 作为学生，我希望默认看到主关系、按需看辅助关系及全部关系，以便兼顾阅读和联系追溯。
22. 作为学生，我希望关系显示保留含义、方向、来源和 AND/OR 路线，以便不把聚合线或排版顺序误读成必修前置。
23. 作为学生，我希望主题重要性、单元重要性和个人复习状态明确区分，以便正确安排复习。
24. 作为学生，我希望为 B 选择待复习、薄弱或已掌握，A 仅汇总并支持筛选定位，以便记录自己的情况。
25. 作为学生，我希望已掌握内容实质变化后收到状态调整询问，确认前保留原标记，以便掌握程度由我决定。
26. 作为学生，我希望随时编辑文字、笔记和公式，以便修正自己的表达或已发现的错误。
27. 作为学生，我希望通过可视化符号和结构编辑公式，以便无需先学习 LaTeX 源码。
28. 作为学生，我希望绘制基础形状、箭头、直线、波浪线和高亮，并移动、调整对象大小，以便表达理解和提醒。
29. 作为学生，我希望手画箭头默认作为个人标注，以便随手联想不会成为正式知识事实。
30. 作为学生，我希望明确选择建立知识关系并提供含义与依据，以便正式关系可理解、可追溯。
31. 作为学生，我希望同时支持对象笔记和片段批注，以便记录整体理解或针对某句话的疑问。
32. 作为学生，我希望内容移动、改写或删除后笔记和原引用仍可找到，以便不丢失自己的思考。
33. 作为学生，我希望拆分合并后明确对应的笔记自动跟随，不确定的保留并提示重新关联，以便避免错误复制。
34. 作为学生，我希望点击来源在同页打开正确资料版本和原页，以便核对依据且保留画板位置。
35. 作为学生，我希望原文选段携带出处进入提问，以便无需手工搬运上下文。
36. 作为学生，我希望画板、原文和 Agent 可按需并排、调宽或收起，以便兼顾对照和当前操作区域的可读性。
37. 作为学生，我希望收起再恢复各区域时保留视口、页码、草稿和选择，以便继续当前任务。
38. 作为学生，我希望真实 Agent 获得所选对象、片段、出处和请求，以便围绕准确目标回答。
39. 作为学生，我希望普通问答先在侧栏回答，明确要求添加或点击加入时才写画板，以便控制学习内容的变化。
40. 作为学生，我希望同一课程可以保存多段对话并默认继续最近一段，以便长期积累解释。
41. 作为学生，我希望切换对话不切换或回退画板，以便所有对话共同服务当前课程。
42. 作为学生，我希望 Agent 优先依据课程资料并区分原文与补充解释，以便清楚回答的依据。
43. 作为学生，我希望明确的改写、纠错、补充、扩展、整理或精简请求直接修改对应内容，以便不用另走预览采纳步骤。
44. 作为学生，我希望纠错同步修正直接受影响的主内容，以便公式、图示和例题不留下已知矛盾。
45. 作为学生，我希望任务绑定提交时的目标，后续浏览不改目标，以便可以一边等待一边继续阅读。
46. 作为学生，我希望同一画板的修改默认排队、开始时读取最新内容，而问答和阅读可继续，以便避免任务互相覆盖。
47. 作为学生，我希望 Agent 工作时能获知我的中途编辑并保留最新内容，以便不会被旧结果覆盖。
48. 作为学生，我希望同时修改即使顺利整合也明确说明涉及位置和处理结果，只有不兼容部分才询问，以便理解发生了什么。
49. 作为学生，我希望任务完成只提示改了哪里并提供前往入口，以便不被强制跳走视口。
50. 作为学生，我希望停止任务保留已完成修改，撤回另行执行，以便控制后续工作而不误删已有结果。
51. 作为学生，我希望撤回一次 Agent 修改仍保留后来写下的个人笔记，以便有针对性地恢复内容。
52. 作为学生，我希望整幅历史状态有单独的版本回退入口，以便不会把导航返回、撤回一次修改和历史恢复混淆。
53. 作为学生，我希望重开时先恢复已保存内容、核对任务实际状态，未完成任务由我点击继续，以便不静默重跑或重复应用。
54. 作为学生，我希望关键词搜索默认覆盖知识、笔记、对话和原文，也可选择范围，以便查找已有内容。
55. 作为学生，我希望描述性线索返回真实存在、可定位的命中，以便在忘记术语时找回内容。
56. 作为学生，我希望新增或替换资料后由我决定是否更新画板，以便资料变更不会擅自改动正在复习的内容。
57. 作为学生，我希望暂不更新时保留旧画板和旧引用，Agent 可使用新版但说明差异与版本，以便比较新旧依据。
58. 作为学生，我希望 Agent 能按请求添加可操作的学习示例，以便改变输入、观察输出并检验理解。
59. 作为学生，我希望整个界面保持手绘笔触、端正排版和有信息含义的内容配色，以便新功能延续已经认可的阅读体验。
60. 作为学生，我希望启动、保存或 Agent 出错时看清实际状态并继续阅读已有内容，以便知道哪些结果已经保存、哪些仍待处理。

## Implementation Decisions

### 已确认的产品规则

- 领域词汇采用主题 A、单元 B、知识主位置、知识引用、来源引用、个人笔记、复习状态、学习请求与 Agent 任务；不另发明同义实体。
- 五项阅读要求和三项视觉要求贯穿每张相关票；完整内容只决定显示深度和收纳，不退化为外链索引或等待生成的空壳。
- 范围、单元身份、评级、关系语义沿用正式课程数据。`KU-049`、`KU-073` 不属于当前有效单元，不能填补空号。主/辅助是显示级别，不能用来判断前置必要性。
- 老师课件确定课程语境，课本补充解释与核对，既往课程笔记提供讲法、推导和提醒；采纳须记录出处。不能仅因笔记篇幅改变范围与评级，也不能把个人笔记和课程参考笔记混用。
- 普通回答先进入侧栏是暂定采用的交互；实现时直接采用，不把它列为阻塞问题。明确修改与加入画板直接生效，内容检查是提交完整有效数据的技术条件，不是用户预览采纳门槛。

### 本次确定的实现边界

- 本地服务采用 Python，复用现有知识数据模块；浏览器使用模块化前端，承接已验证的画板操作和本地字体、公式、手绘资源。执行器首先适配独立 Codex app-server 会话。其余框架或内部存储细节可在不改变合同的情况下调整。
- 主要行为边界为 `CourseService`：课程查询、命令提交、事件订阅和来源定位统一经过此边界。前端模块与执行器不各自写课程文件，既有知识查询模块继续唯一解释课程语义。
- 权威知识数据增加经过校验的单元阅读材料；完整正文只保存一次。布局、个人内容、阅读上下文、任务及对话分别保存；浏览器缓存和搜索索引均可重建。
- 资料引用绑定稳定来源 ID、资料版本及位置；旧版依据随课程保留。PDF 页序和教材中文书页分别保存，课程笔记使用文档小节等真实位置，不能伪造 PDF 页码。
- 内容块、题目、资料版本、笔记、任务、操作与视觉对象各有稳定身份。知识单元 ID 不因正文或布局改变而改变；笔记保留书写时的引用和版本。
- 全部修改进入统一命令通道，含目标、预期版本和操作 ID。校验、保存、事件与撤回记录作为同一行为处理；重复操作不重复生效，旧版本不能覆盖最新内容。只读问答与排队修改分别管理。
- Agent 的运行记录与应用提交记录分别保存；模型返回成功不等于课程已保存。网页持有业务任务 ID 与执行器会话映射，不依赖复用当前 Codex 桌面聊天。
- 同时修改在任务执行期间通知 Agent，完成说明保留具体位置和处理结果；单靠最终版本拒绝不能算完成此要求。停止与撤回分开，恢复先核对事实再提供继续。
- 学生个人笔记独立于知识正文。选择性撤回应用该次修改的逆向变更并检查后续编辑，不能通过恢复整份课程旧快照抹掉后续笔记。
- 交互示例以可持久化的描述和受支持的组件渲染；图、控制、输出共享同一语义配置。未经绑定的公式不能声称已自动驱动电路，内容修改后旧交互也不能继续冒充一致结果。
- 本地内容包仅是待导入的修改提案。正文工作线内部可按章节分工、独立验证，再由一个集成者串行写入权威数据；这些分工不是新的票据，运行中的应用不读取另一套分包正文库。

字段、错误、版本、接口与接入阶段以 [数据与行为合同 v1](02-数据与行为合同.md) 为准。并行所有权、现有入口和验证命令集中于 [并行实施与验证](03-并行实施与验证.md)，不在各票中复制实现路径。

## Testing Decisions

- **主要测试接缝是本地 `CourseService` 的外部行为。** 使用临时课程副本启动真实本地服务，经过查询、命令、事件和来源入口验证；检查重新打开后的文件状态，而不是只断言内存对象或内部函数被调用。
- **浏览器验证覆盖用户实际路径。** 至少验证启动、选择和编辑、原位展开、三级缩放、引用返回、保存重开以及真实 Agent 结果。视觉、原文选段、触控板和窗口适配不能由 JSON 测试替代。
- **仅在执行器端口使用可控替身注入异常。** 用于精确制造中途编辑、乱序或重复事件、断线和中断；真实 Codex 另做最小集成验收，验证问答、修改、运行中编辑通知及恢复。旧协议探针是依据，不是新应用的通过记录。
- 复用已有知识地图检查及 15 项接口测试的习惯：稳定 ID、关系过滤、前置 AND/OR、题目 direct/support、错误与源/派生一致性。内容变更只在临时副本做破坏性实验；正常集成按源检查、构建、完整检查、相关测试完成。
- 保存验收涵盖刷新、服务退出重启、写入中断、重复提交、不同浏览器实例和课程目录迁移。失败时不能显示“已保存”，已确认保存的内容不能丢失。
- 撤回与并发测试必须包含学生后来写的笔记、后来手工修改同一片段、任务期间选择变化、排队任务启动前目标变化；避免只测试无并发的顺利路径。
- 内容验证以学习目标和原文为准。公式、反相线、表格、电路、引脚及题目边界须实际查看原页；教材使用既有检索入口，记录中文书页与 PDF 页序。普通作业推导解答与官方答案、编制自测明确区分。
- 对布局和文案等可逆低影响修改，以相关浏览器检查和内容审查为主，不新增仅复述实现的测试。每票只运行相称检查；出现新问题时再扩大范围。
- 全部资料与资源的离线运行、完整 84 单元覆盖以及五项阅读和三项视觉要求在最终整体验收时复核；已有成功检查不因换票号而机械重复。

## Out of Scope

- 自动从新资料抽取整套知识结构；首版使用已交付的知识地图，新增资料的版本保存和是否更新的选择仍在范围内。
- 其他 Agent 执行器的实现、接管当前桌面已有聊天、把内部桌面工具当成公开产品接口。
- 多人实时协作、云同步或公开托管；本规格覆盖本地单人学习及多个开发 agent 协作实施。
- 主题切换、自定义皮肤，以及偏离现有课程范围的 HDL 代码教学内容。
- 重新拆分全部知识、重评已有星级、为图形丰富度新增关系，或把每种材料机械变成节点。
