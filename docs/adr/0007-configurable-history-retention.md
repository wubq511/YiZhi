# 可配置的正式历史保留期限

Robert 选择按期限自动清理正式修改历史，并明确**默认 140 天，学生可在设置中调整**。课程保存自身的保留天数，新课程默认 140 天；它控制旧修改详情和恢复记录的保留范围，以可预期的回查窗口换取历史体量的控制，替代先前不按时间自动删除的推荐。

当前内容、个人笔记、学习对话、未处理草稿及仍被引用的资料独立保留；清理必须保留恢复窗口起点的必要状态、窗口内完整变更组和操作去重事实。设置调大只能延长今后的保留，不能找回已经清理的记录；调小后按新期限自动处理，并明确当前可恢复范围。课程迁移携带该设置，独立备份的保存与清理不由此期限自动决定。具体清理、重建与故障恢复见[历史设计](../architecture/历史管理与恢复设计.md#保留与清理)。
