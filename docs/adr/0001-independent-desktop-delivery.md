# 独立桌面作为默认交付形态

下一版采用独立桌面应用，统一提供课程打开、学习窗口、本机运行组件、后台任务状态和明确退出入口。本地服务＋外部浏览器同样可实现核心能力，但本产品需要持续管理本地课程和窗口关闭后仍运行的任务，也没有必须使用浏览器的场景；Robert 在比较完整使用路径与安装、打包、更新成本后接受桌面方案。

当前先实施和打磨 macOS；Windows 是后续发布推广前必做的平台，现在纳入课程可移植格式、依赖选择和系统差异设计，具体适配与实机验收后做。此决定不锁定 Electron、Tauri、界面框架、后端语言或数据库，也不构成桌面更快或更省资源的性能结论。完整依据见[产品形态与运行架构比较](../research/architecture/产品形态与运行架构比较.md)。
