# React Flow 空间底座与独立学习内容层

沿用本会话已经形成并用于隔离验证的 TypeScript／React＋React Flow 工作区设计：React Flow 管理空间对象、关系线、选择和视口，独立 DOM 学习内容层承载完整正文、公式、实验及其编辑现场；课程知识、个人内容和布局由课程核心管理，不把画布场景作为另一份权威课程。完整学习内容是主要负载，这条路线可直接控制文本选择、局部更新与组件生命周期；接受自行补齐基础绘图、批注、局部布局和输入协调的成本。

比较过 Excalidraw 富内容扩展、自建空间底座及 tldraw；Excalidraw 能复用更多现成绘图能力，React Flow 更符合本次已验证的 DOM 内容组织；tldraw 的生产许可不符合既定依赖约束。已有[固定负载](../../experiments/architecture-spike/验证记录.md)与[动态布局](../../experiments/architecture-spike/动态布局验证.md)证据支持路线，不代替正式编辑器、真实输入法、自由布局和完整课程持久化的组合验收。此次收敛沿用既有设计，不重新开启画板底座比较。
