# 学习产品、开发工具与自动维护分开

桌面应用把旧版课程迁入、迁移记录、可控生产者和手动课程格式升级放进了学习界面。前三者服务项目开发与验证，格式升级服务应用自身维护；这些工程需要不构成学生任务。Robert 明确要求旧版迁入保留为独立开发工具，可控生产者退出正式界面，格式升级由应用自动完成。已有桌面课程保留必要的读取兼容，不以删除入口为由删除课程数据。

当前取消所选单元／批注的内容交换能力。整课画板分享是可能有用的另一项产品需求，但本期不做，也不为未来分享维护当前交换流程。该决定收窄 [ADR-0004](0004-sqlite-course-storage.md) 当时接受的开放交换范围，保留 SQLite 存储、完整备份及课程格式演进的选择。

选择在开发工具和正式产品之间建立代码、入口与交付边界，接受独立验证工具的组织成本；拒绝把开发面板折叠、改名或移入用户设置后继续作为产品功能。行为合同见 [PRODUCT.md](../../PRODUCT.md)，工程分工见[系统设计定稿第 8 节](../architecture/系统设计定稿.md#8-课程格式备份与交付)。本记录确认决策；2026-10-30 已完成代码拆分与自动打开接线，实际运行与验证边界见[桌面应用说明](../../desktop/README.md)。
