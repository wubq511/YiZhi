# 可读概览与完整主关系

课程画板需要随着主题增长继续支持阅读与学习。远景优先呈现可辨认的学习结构，不要求任何规模的课程都在一屏读清全部主题名称。空间组织直接作用于既有主题 A 与单元 B；不在 A 之上新增分区、主题集合或其他导航层级。增加一个命名分区层并没有解决主题自身如何排布及关系如何走线的问题，且改变了既有知识层级，因此不采用。

Robert 同时明确选择全图默认展示全部主关系，拒绝以“全图只保留少量关键联系，选中主题后再显示其余关系”作为默认体验。远景沿用关系聚合，近景呈现对应层级的关系；显示层级可以改变，主关系集合不因当前注意焦点或视觉拥挤而被二次筛选。辅助关系仍按需展开。

主题排布、显示深度和关系走线共同承担可读性。采用内容决定的主题占地、有规则的对齐与间距、真实前置的方向偏好、可追溯聚合和关系通道；缩远保留单元缩略结构。含义准确、内容不遮挡和位置稳定优先于减少交叉，再优先于紧凑。接受复杂图中的回向线、必要交叉和更多空间，不通过增加层级、抽样关系或压小文字换取表面整洁。

布局由应用的共享模块执行，依据已保存的课程结构、关系和顺序，不依赖某个 Agent 临时决定坐标。首次课程内容在应用外准备，导入后的学生编辑与学习 Agent 修改沿用同一布局能力；重开与恢复不重新优化。分开维护持久基线、临时阅读投影和缩放显示，使持续修改与空间记忆可以同时成立。

产品行为以 [PRODUCT.md](../../PRODUCT.md) 为准，共享模块、写入入口和验收要求见[画板布局设计](../architecture/画板布局设计.md)。本记录说明已确认取舍，不代表布局机制已经实现或验收。
