# Tiptap、ProseMirror 与 MathLive 承载正文编辑

Robert 已选择 Tiptap 开源核心＋ProseMirror 事务与历史＋自定义 MathLive 公式控件。每个活动知识单元提供连续正文编辑上下文，按需使用常规扩展和稳定块 ID 能力；独立范围更新使用 ProseMirror 事务维护可映射的选区与局部历史，公式内部由 MathLive 处理，课程核心负责草稿、正式提交和历史事实。

相比直接组合 ProseMirror，该方案减少常规扩展组织与 ID 处理的重复实现，接受 Tiptap 扩展与底层事务配合的维护成本。直接 ProseMirror 是已比较备选；Lexical 默认快照历史还需要额外解决外部更新后的局部撤销，因此本次不采用。所需能力使用已核查的宽松开源组件，不依赖厂商 Pro、云协作或 AI 产品；实际包版本保持兼容并锁定，不能直接拼接研究时各上游 HEAD。[候选机制与许可依据](../research/topics/正文编辑器候选核查.md)

决定不等于集成验收：ID 拆合与粘贴、公式内外快捷键和历史衔接、中文输入、Agent 并发更新与真实保存均须通过[组合场景](../architecture/正文编辑与保存衔接设计.md#下一项有界组合验证)。普通后台更新不得通过整文重设或重建实例清空学生的全部撤销。
