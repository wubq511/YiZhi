# 数字逻辑课程基线

- 本目录是课程根，YiZhi 仓库根是 `../..`。课程专用命令从本目录运行。
- 查询、修改、校验或重建知识地图时使用 [.agents/skills/digital-logic-midterm-map/SKILL.md](.agents/skills/digital-logic-midterm-map/SKILL.md)。
- 检索、读取或引用教材时使用 [.agents/skills/digital-logic-textbook/SKILL.md](.agents/skills/digital-logic-textbook/SKILL.md)。
- 既有完整知识、分类、层级与正文是开发基线，不因迁移项目或搭建新版应用而重新生成内容。
- 权威内容在 `期中/数据/知识地图.json`，独立布局在 `期中/数据/视图布局.json`；个人状态在 `.review-board/状态.sqlite3`。只读核验不要启动写入流程。
- 通用拆分与评级规则在仓库的 [docs/knowledge/](../../docs/knowledge/README.md)。已完成的审核依据在 `期中/待审查/` 与 `provenance/`，不作为第二份可写权威。
