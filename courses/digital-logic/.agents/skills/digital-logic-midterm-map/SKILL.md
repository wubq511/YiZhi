# 期中知识地图

本 Skill 位于 `<课程根>/.agents/skills/digital-logic-midterm-map/`。课程根为 YiZhi 仓库的 `courses/digital-logic/`；以下命令均从课程根运行。使用 `期中/工具/知识地图.py` 作为统一查询、校验和构建入口，不要从 Markdown 或显示标签猜测实体身份和关系。

## 权威修改位置

- 课程内容只修改 `期中/数据/知识地图.json`。
- 布局只修改 `期中/数据/视图布局.json`。
- Markdown、HTML、画板图和其他派生产物通过构建更新，不手工修改。

ID 必须稳定且目标存在。退休 ID 不重新分配，也不加入当前映射或关系。

## 按任务选择流程

### 查询知识、题目或关系

1. 用 `get` 按稳定 ID 精确读取；需要名称查找时用 `search`，并查看全部匹配及主题上下文，特别是 `LE` 等重名别名。
2. 用 `related` 查直接前置、全部前置或指定关系；前置追溯只使用 `requires`，需要时保留路线组。
3. 用 `path` 在指定关系子图中查路径，不把构造、优化、互逆或来源引用混当前置。
4. 用 `questions` 按单元和 `direct / support` 查题目。题目支撑不自动等于学习前置。
5. 用 `graph` 获取画板所需的节点、关系、主题聚合和布局引用。`main` 为主图，`auxiliary` 为辅助图，`all` 为全部已审核关系。
6. 输出使用稳定 JSON。区分 `not_found`、无结果和非法参数；错误没有查清前，不把模糊重试当成解决。

常用示例：

```bash
python3 期中/工具/知识地图.py get KU-064
python3 期中/工具/知识地图.py search 'LE' --limit 0
python3 期中/工具/知识地图.py related KU-044 --depth -1
python3 期中/工具/知识地图.py path KU-028 KU-044
python3 期中/工具/知识地图.py questions KU-083 --role direct
python3 期中/工具/知识地图.py graph --view all
```

需要完整参数时查看 `--help`，不凭记忆猜选项。

### 修改内容或关系

1. 先读与修改类型对应的规则，再改权威文件：
   - 范围、排除项和题型：`期中/设计/01-课程知识地图设计.md`。
   - 粒度：`../../docs/knowledge/知识点拆分规则.md`。
   - 评级：`../../docs/knowledge/重要性评级规则.md`。
   - 关系价值与呈现：`期中/设计/02-知识关系价值与呈现规则.md`。
   - ID、布局、AND/OR 和一致性：`期中/设计/04-数据与消费接口.md`。
2. 保持主题、单元、题目、映射、关系和视觉元素的 ID 命名空间分离。内容修改不改变 ID；需要退休时保留退休记录和替代目标。
3. 新关系必须写清额外信息、画布收益、方向和来源。公式、名称、层级或题目映射已经表达的信息不重复建边。
4. 多条 `requires` 入边默认表示全部必要。可替代前置必须放入路线组并声明 `all / any`；不能压平为全部必需。构造、优化、互逆不进入前置追溯。
5. 主题 A 按核心学习表现和主题层证据独立评级；单元峰值与分布由模块计算，不用平均值或峰值代替整体评级。
6. 涉及教材原页时调用 `digital-logic-textbook`。公式、反相线、真值表、卡诺图、电路连线和芯片引脚影响含义时，必须查看原图。

### 校验与重建

1. 先运行源数据检查：

   ```bash
   python3 期中/工具/知识地图.py check --source-only
   ```

2. 只读校验或文件迁移直接运行 `check` 检查现有派生产物，不重新生成课程内容。权威数据、布局或生成器确有改动时，再构建消费产物并检查一致性：

   ```bash
   python3 期中/工具/知识地图.py build
   python3 期中/工具/知识地图.py check
   python3 -m unittest discover -s 期中/工具 -p 'test_*.py'
   ```

3. 修改 HTML 后，在真实浏览器检查平移、缩放、复位、搜索、筛选、点击查看和离线资源。数据校验不能替代页面验收。
4. 只在临时副本中做破坏性测试。可用 `MIDTERM_MAP_FILE`、`MIDTERM_OUTPUT_DIR`、`MIDTERM_LAYOUT_FILE` 指向副本，避免改动正式数据。

## 完成标准

- 请求的实体、题目或关系均返回稳定 ID、来源和必要证据，未知项明确报错。
- 主题、单元、题目、映射、关系和布局引用完整，评级与关系有依据。
- Markdown、HTML、Agent 查询和画板图的 ID、数量、星级和关系一致。
- 源检查、构建检查、接口测试及相应原页或浏览器检查通过。
- 不将未验证的识别内容、静态图或未运行结果称为已完成。
