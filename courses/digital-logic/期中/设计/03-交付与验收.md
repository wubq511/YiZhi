## 3. 产物职责

| 产物 | 职责 | 不负责 |
| --- | --- | --- |
| 课件知识点清单 | 展示课次、主题、单元、类型、掌握目标、来源和重要性 | 完整讲义、所有例题推导 |
| 题目知识点映射 | 逐题连接知识单元，区分直接考查与前置支撑 | 用完整题解代替映射 |

| 画板图数据 | 提供已审核节点、关系、分组和布局引用 | 从视觉箭头猜测语义 |
| 校验与构建 | 检查引用、语义、一致性和可重复构建 | 替代课程语义审核 |

## 4. 数据与维护规则

数据实体、稳定 ID、AND / OR 前置、布局分离、Agent 操作和画板消费方式统一维护在[数据与消费接口](04-数据与消费接口.md)。

维护时只修改权威知识数据或布局。Markdown、HTML 和图数据通过构建更新，再运行完整检查。个人笔记、视口和选中状态不写入课程权威数据。

## 5. HTML 首版能力

首版提供本地只读浏览：

- 平移、缩放、复位和按主题聚焦。
- 按名称、别名或单元 ID 搜索。
- 按课次、主题、星级和题型筛选。
- 点击主题、单元或关系查看详情、来源、评级理由与关联题目。
- 切换主图、辅助图和全部关系视图，以线型区分关系。
- HTML、CSS、JavaScript 与地图数据内嵌，无外部 CDN 或运行时安装依赖。

使用自包含 SVG 画布实现这些交互；页面不依赖 Mermaid。`file://` 直开与 PDF 查看器的未验证部分见第 8 节。

## 6. 验收口径

### 内容与来源

- 第 01–06 课每个非排除主题都已索引，或明确记录为背景与排除理由。
- 第 01–06 次作业及补充要求逐题映射，习题课 12 组例题逐题映射。
- 所有公式、反相线、真值表、卡诺图和电路连接均按需要查看原页，不凭文本提取猜补。
- 教材只用于校准范围内的表述，引用具有双页码。
- SystemVerilog/HDL 和实验内容不出现在正式知识单元中。

### 映射与评级

- 每道题至少有一个直接考查单元，或明确说明无法确定的原因。
- 直接考查与前置支撑没有混用。
- 每个四星、五星单元都有可回查证据，每次上调均有理由。
- 主题具有核心学习表现和主题层评级理由；单元峰值与星级分布由数据计算。

### 关系与机器接口

- 每条关系都有额外信息、画布收益、明确方向和来源，没有悬空 ID 或重复传递边。
- 前置追溯只使用明确的 `requires` 子图，并保留 AND / OR 路线条件。
- Agent 能按稳定 ID、中文名称、题目和关系精确查询；未知 ID 和非法参数返回明确错误。
- Markdown、HTML、Agent 查询与画板图的 ID、数量、评级和关系一致。
- 派生产物可从权威数据重新生成并比较，重复构建顺序稳定，内容更新不无意破坏布局。
- 项目 Skill 能引导 Agent 完成查询、修改、校验和重建；`期中/AGENTS.md` 只保留 Skill 入口与权威修改位置。
- Skill 的查询、条件语义和修改用例通过检查，并生成结果与评审页供 Robert 查看。

### HTML

- 在本地浏览器实际完成平移、缩放、搜索、筛选、点击查看和复位检查。
- 无外部网络时仍能阅读已有内容。
- 页面显示的知识、评级、题目和关系与权威数据一致。
