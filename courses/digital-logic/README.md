# 数字逻辑与部件设计

YiZhi 的首个完整开发课程，沿用已有的 **20 个主题、84 个有效知识单元**。迁入内容包括既有分类、层级、重要性评级、关系、完整 reading、题目映射、资源、原文和个人状态；未重新生成知识。

| 入口 | 用途 |
| --- | --- |
| [课程清单](课程.json) | 稳定课程身份与课程内相对路径 |
| [期中导航](期中/README.md) | 知识地图、课程设计和审核资料 |
| [知识地图 JSON](期中/数据/知识地图.json) | 当前权威内容、正文、关系、评级与来源版本 |
| [视图布局](期中/数据/视图布局.json) | 独立布局与视觉身份 |
| [资料说明](资料说明.md) | 教材、课件、习题、实验与笔记的来源组织 |
| [内容核验溯源](provenance/README.md) | 已完成内容生产的独立核验记录 |
| [课程维护约定](AGENTS.md) | 查询、校验和教材技能入口 |

`期中` 是既有数据目录名，保留是为维持稳定引用；它不把下一版产品限制为只支持期中复习。

从 YiZhi 仓库根运行 `python3 legacy/review-board/start.py`，即可继续使用完整课程。旧版运行资源在仓库的 `legacy/` 与 `experiments/`；课程目录仅保存课程内容、资料和状态。

以下命令从本课程目录运行，不修改知识内容：

```bash
python3 期中/工具/知识地图.py check --source-only
python3 期中/工具/知识地图.py check
python3 期中/工具/知识地图.py search '译码器' --limit 0
```

`.review-board/状态.sqlite3` 保留笔记、掌握状态、对话、任务、历史与阅读现场；迁移使用包含 WAL 的一致数据库快照。教材、课件、习题、实验、笔记和这个个人状态目录只保存在本机，不进入 Git。备份前先停止课程服务，再复制完整课程目录；恢复旧版基线还需要兼容的 YiZhi 运行代码。
