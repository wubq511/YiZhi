# 数字逻辑课程

YiZhi 的首个完整课程基线：20 个主题、84 个有效知识单元，保留现有分类、层级、重要性、关系、完整正文、题目映射、资料版本及个人状态。

## 查阅内容

| 入口 | 内容 |
| --- | --- |
| [课程清单](课程.json) | 稳定课程身份及数据位置 |
| [权威知识](期中/数据/知识地图.json) | 当前主题、单元、完整 reading、题目与来源 |
| [独立布局](期中/数据/视图布局.json) | 坐标、分组和视觉身份 |
| [可视化知识地图](期中/知识地图.html) | 直接浏览、搜索与追溯知识结构 |
| [知识清单](期中/01-课件知识点.md)／[题目映射](期中/02-题目知识点映射.md)／[关系索引](期中/03-知识点地图.md) | 供人和 Agent 快速查阅的派生视图 |
| [内容范围与核验依据](../../docs/knowledge/数字逻辑课程基线.md) | 课程规范、已做修正、完整性及证据 |

从仓库根运行 `python3 legacy/review-board/start.py` 可使用现有复习应用。查询和校验工具集中在 [tools/](../../tools/README.md)，维护技能集中在根目录 `.agents/skills/`。

## 资料目录

| 位置 | 保留内容 |
| --- | --- |
| `理论课/课件/` | 教师第 01–06 课原版 PDF |
| `理论课/课后作业/` | 第 01–06 次原作业，及第 04 次网页补充要求 |
| [作业整理版](理论课/课后作业/整理版/README.md) | 每份附齐对应教材原题页；第 04 次含网页补充要求，06 的 5.55 含实际引用的前置函数和图 |
| `习题课/` | 教师指定的 18 页组合习题及答案，含 12 组例题 |
| [教材检索数据](教材/数字设计和计算机体系结构-检索版/README.md) | 原 PDF、全书 OCR、章节文本、目录与页码；检索数据有独立用途，不作为重复文档删除 |
| `笔记/` | 5 份既有课程笔记及其图片，作为讲法、推导和易错提醒的原始参考 |
| `实验课/` | 原有实验 01 资料；当前知识范围明确排除实验与 HDL，原始课程资料仍完整保留 |
| `期中/资源/` | 正文使用的图示和器件手册 |

01–03 作业是网页整理 PDF，04–06 是教师原 PDF。作业合并版保留原题、反相线和图表；相似教材题不冒充实际作业。完整页码对照由作业整理版入口维护。

`期中` 是已有课程数据目录名，保留以维持来源和资源引用。学习状态在 `.review-board/状态.sqlite3`；原始教材、课件、笔记及个人数据库保存在本机，由 `.gitignore` 排除。备份先停止课程服务，再复制完整课程目录；Git 克隆不包含这些本机资料与状态。
