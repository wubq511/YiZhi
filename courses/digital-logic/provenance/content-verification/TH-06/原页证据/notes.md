### p30（c02-p30-30.png，已看）
- 标题「基本形式」+「标准形式」。例：与-或（SOP）`F = A + ĀB + AB̄C`，逐项吸收化简得 `F = A + ĀB`。
- 或-与（POS）例：`F = A(Ā+B)(A+B̄+C)`。
- 结论：同一函数的基本形式不唯一 → 引入标准形式。
- 标准与-或（最小项之和）例：`F = ĀB̄C + AB̄C + ABC`。
- 标准或-与（最大项之积）例：`F = (A+B+C)(A+B̄+C)`。

### p33（c02-p33-33.png，已看）真值表 → 表达式
- 约定：变量取 1 用原变量，取 0 用反变量。
- 2 变量例：S 列仅 (0,1) 和 (1,0) 两行为 1 → `S = Ā·B + A·B̄`。
- 3 变量例：F 列仅 011 行为 1 → `F = Ā·B·C`；G = F̄（G 列仅 011 行为 0）→ `G = F̄ = (Ā·B·C)‾ = A + B̄ + C̄`，即从 F 的唯一 1 行反推出 G 的标准或-与式（该行取值 0→原变量、1→反变量）。

### p34（c02-p34-34.png，已看）最小项 minterm / 最大项 maxterm
- 最小项：n 变量"与项"包含全部 n 个变量，每个变量以原/反形式仅出现 1 次；n 变量共 2ⁿ 个。
- 最大项：n 变量"或项"包含全部 n 个变量，每个变量以原/反形式仅出现一次；n 变量共 2ⁿ 个。
- 2 变量最小项：m0=x̄ȳ(00)、m1=x̄y(01)、m2=xȳ(10)、m3=xy(11)。编号=使其为 1 的取值组合。
- 2 变量最大项：M0=x+y(00)、M1=x+ȳ(01)、M2=x̄+y(10)、M3=x̄+ȳ(11)。编号=使其为 0 的取值组合。
- 左右是两个独立示例（不是同一函数！）：左 F=ĀB̄C̄+ĀB̄C+ĀBC̄+ĀBC+ABC=Σm(0,1,2,3,7)；右 F=(A+B+C)(Ā+B+C)(Ā+B̄+C̄)=ΠM(0,4,7)（三个最大项分别在 000/100/111 行为 0）。

### p35（c02-p35-35.png，已看）【例】用标准式表示
- F1 = x̄ȳz̄+x̄yz+xȳz̄ = Σm(0,3,4)
- F2 = Σm(1,2,5,6,7) = x̄ȳz+x̄yz̄+xȳz+xyz̄+xyz
- F3 = (x+y+z̄)(x+ȳ+z)(x̄+y+z̄)(x̄+ȳ+z)(x̄+ȳ+z̄) = ΠM(1,2,5,6,7)
- F4 = M0M3M4 = ΠM(0,3,4) = (x+y+z)(x+ȳ+z̄)(x̄+y+z)
- 隐含配对：同一编号集合的 Σm 与 ΠM 互为反函数——F3 = ΠM(1,2,5,6,7) = F̄2，F4 = ΠM(0,3,4) = F̄1（由 mi=M̄i 推出）。

### p36（c02-p36-36.png，已看）最小项、最大项性质
n 变量任意取值下：
① 必有且仅有一个最大项值为 0；必有且仅有一个最小项值为 1。
② 不同最小项之积为 0（mi·mj=0, i≠j）；不同最大项之和为 1（Mi+Mj=1）。
③ 全体最小项之和为 1；全体最大项之积为 0。
④ 下标相同的最小项与最大项互为反函数：mi = M̄i。
- 3 变量完整对照表（000→m0=x̄ȳz̄/M0=x+y+z，001→m1/M1=x+y+z̄，010→m2/M2=x+ȳ+z，011→m3/M3=x+ȳ+z̄，100→m4=xȳz̄/M4=x̄+y+z，101→m5/M5=x̄+y+z̄，110→m6=xyz̄/M6=x̄+ȳ+z，111→m7=xyz/M7=x̄+ȳ+z̄）。

### p37（c02-p37-37.png，已看）同一逻辑问题，表达式之间的关系
- 关系① 函数与反函数互补：若 F = Σmi，则 F̄ = ΠMi（同一下标集合）。
- 关系② 两种范式：若 F = Σmi，则 F = ΠMj，其中 j≠i（下标集合互补）。
- 例：F(ABC)=Σm(0,1,3,6,7)，求和之积形式及 F̄。
  - F̄ = ΠM(0,1,3,6,7) = (A+B+C)(A+B+C̄)(A+B̄+C̄)(Ā+B̄+C)(Ā+B̄+C̄)
  - F = ΠM(2,4,5) = (A+B̄+C)(Ā+B+C)(Ā+B+C̄)
- 右侧真值表验证：ABC=000→1, 001→1, 010→0, 011→1, 100→0, 101→0, 110→1, 111→1。

### p38（c02-p38-38.png，已看）转标准与-或式 方法1（真值表法）
- 例 Y = ABC̄ + BC，列真值表逐行求 Y：000→0,001→0,010→0,011→1,100→0,101→0,110→1,111→1。
- Y 为 1 的行：011、110、111 → Y(A,B,C)=Σm(3,6,7)。

### p39（c02-p39-39.png，已看）转标准与-或式 方法2（补因子法）
- 步骤：①化为若干乘积项之和（积之和）；②利用 A+Ā=1 将每个乘积项缺少的因子补全。
- 同一例：Y = ABC̄+BC = ABC̄+(A+Ā)BC = ABC̄+ABC+ĀBC = m6+m7+m3 = Σm(3,6,7)。

### p40（c02-p40-40.png，已看）【练习1】F = A+B̄C 转标准与-或式（含答案）
- F = A(B+B̄)+B̄C = AB+AB̄+B̄C
- = AB(C+C̄)+AB̄(C+C̄)+(A+Ā)B̄C
- = ABC+ABC̄+AB̄C+AB̄C̄+ĀB̄C（Note: Remove Duplicates——补因子可能产生重复最小项，要去重）
- = m1+m4+m5+m6+m7 → F(A,B,C)=Σm(1,4,5,6,7)。

### p41（c02-p41-41.png，已看）转标准或-与式 方法1（真值表法）
- 例 Y = ĀB+AC，真值表逐行：000→0,001→0,010→1,011→1,100→0,101→1,110→0,111→1。
- Y 为 0 的行：000,001,100,110 → Y(A,B,C)=ΠM(0,1,4,6)。

### p42（c02-p42-42.png，已看）转标准或-与式 方法2
- 步骤：①化为或-与（和之积）；②利用 x·x̄=0（在或项内加 xx̄=0 项再展开）补齐缺失变量；重复最大项去重。
- 分配律工具：x+y·z=(x+y)(x+z)。
- 同一例 Y=ĀB+AC=(ĀB+A)(ĀB+C)=(A+B)(Ā+C)(B+C)（A+Ā 消去）→ 补因子后 M0M1M4M6=ΠM(0,1,4,6)，与方法1一致。

### p43（c02-p43-43.png，已看）【练习2】F = xy+x̄z 转标准或-与式（含答案）
- F=(xy+x̄)(xy+z)=(x+x̄)(y+x̄)(x+z)(y+z)=(x̄+y)(x+z)(y+z)
- 补齐：x̄+y=(x̄+y+z)(x̄+y+z̄)；x+z=(x+y+z)(x+ȳ+z)；y+z=(x+y+z)(x̄+y+z)
- 去重后 F=(x+y+z)(x+ȳ+z)(x̄+y+z)(x̄+y+z̄)=M0M2M4M5=ΠM(0,2,4,5)。

### p44（c02-p44-44.png，已看）"与或"→"与或非"
- 【例】用与或非门实现 F = AB̄ + BC̄ + CĀ。
- 方法1：对 F 两次求反：F = (AB̄+BC̄+CĀ)‾‾（双重反线覆盖整个和式）。电路：3 个与门（A·B̄ / B·C̄ / C·Ā）→ 与或非门（或非）→ 反相器，3 级。
- 方法2：对 F̄ 一次求反。F̄ = (AB̄+BC̄+CĀ)‾ = (Ā+B)(B̄+C)(C̄+A) = ĀB̄C̄ + ABC（展开后 4 个交叉项全为 0 被吸收，只剩两头两项），则 F = (ABC + ĀB̄C̄)‾。电路：2 个与门（ABC、ĀB̄C̄）→ 一个与或非门直接输出 F，仅 2 级，速度快（课件注：电路速度快因只经过2级门）。
- 已手工展开验证：F̄ 的最小项集合为 {000, 111}，课件正确。（早期笔记中的"疑似笔误"是本人展开错误，作废。）

### p45（c02-p45-45.png，已看）函数式 ↔ 逻辑图
- 侧栏列出 6 种表示方法：①函数式 ②真值表 ③逻辑图 ④波形图 ⑤卡诺图 ⑥HDL。
- 函数式→逻辑图例：Y = ĀBC̄ + (A+B̄C)‾ + C（首项 Ā·B·C̄ 已放大核对；第二项带长反线，覆盖 A+B̄C）。要点：长反线项整体对应一个复合门，单个变量取反用反相器。
- 逻辑图→函数式例（下方电路，已核对）：两个 3 输入与门分别输出 ĀBC 与 ABC̄（A、C 均有分叉点：原变量直送一个与门、经反相器后送另一个与门；B 直连两门），或门输出 Y = ĀBC + ABC̄（课件印出的答案）。

### p46（c02-p46-46.png，已看）函数式 → 真值表
- 例：Y = A + B̄C + ĀBC̄（放大已核对，第三项为 ĀB·C̄）。
- 方法：真值表设中间列 A、B̄C、ĀBC̄，逐行计算，Y = 三项按行求或。
- 表（已逐行核对）：000→0, 001→1, 010→1, 011→0, 100→1, 101→1, 110→1, 111→1，即 Y = Σm(1,2,4,5,6,7)。

### p47（c02-p47-47.png，已看）真值表 → 波形图
- 表：Y 列 000→0, 001→0, 010→0, 011→0, 100→0, 101→1, 110→1, 111→1（橙色线沿 Y 列描出）。
- 波形画法：输入按二进制递增次序排列——A=00001111、B=00110011、C=01010101，每个时间小区间对应表的一行；Y 按该行值画，波形为 00000111（与表一致，已核对）。Y = Σm(5,6,7)。

### p48（c02-p48-48.png，已看）波形图 → 真值表
- 方法：把时间轴按输入保持不变的区间分段，逐段读出 (A,B,C,Y)，按真值表行序填入；同一组合多次出现只占一行。
- 波形分段核对（放大已核对）：t1–t8 恰按二进制递增次序给出全部 8 种输入组合（A=00000111、B=00110011、C=01010101），逐段读出 Y=0,1,1,0,0,1,0,1，与课件结果表逐行一致；t9–t16 为后续段，同一组合再次出现时不新增行。
- 课件结果表（右侧）：000→0, 001→1, 010→1, 011→0, 100→0, 101→1, 110→0, 111→1，即该函数 = Σm(1,2,5,7)。
