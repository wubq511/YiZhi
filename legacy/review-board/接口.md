# 旧版 CourseService 运行接口

核对日期：2026-10-28。本文描述当前 `legacy/review-board/` 的 Python／Web 实现，收敛旧01–04交接接口；历史功能与验收边界见[旧版运行基线与验收](../../docs/development/旧版运行基线与验收.md)。它不规定下一版的语言、存储或协议。启动、备份和测试命令见[README](README.md)。

## 1. 文件、身份与写入边界

- 应用代码为 `legacy/review-board/`，默认课程根为 `courses/digital-logic/`，可用 `start.py --course /课程目录` 指定完整课程；运行资源来自仓库 `experiments/`，不假定课程根就是产品根。默认地址 `http://127.0.0.1:8769/`，`--port 0` 可分配端口，`--no-browser` 不开网页。同课程已有实例则复用。
- 课程根的 `课程.json` 为 `review-course-1`，含稳定 `courseId/name/knowledge/layout/state`；资源位置均为课程相对路径并检查不越界。默认知识为 `期中/数据/知识地图.json`，权威布局为 `期中/数据/视图布局.json`，个人库为 `.review-board/状态.sqlite3`。
- `KnowledgeCatalog` 通过仓库 `tools/digital-logic/知识地图.py` 解释知识语义（由 `KNOWLEDGE_TOOLS_ROOT` 定位），课程目录保存数据而不再附带工具代码；正式 reading 唯一存于权威知识，当前84单元均有正文。原型四样本仍是兼容回退，不是第二正文库。HTML、索引、原页缓存和内容包不作为当前权威内容。
- 地图生成与正文领域工具同在 `tools/digital-logic/`，教材工具在 `tools/digital-logic/textbook/`，课程技能统一在根 `.agents/skills/`。工具迁移不改变课程数据/资源路径，也不要求把代码再复制回课程。
- 稳定 TH/KU/Q/MAP/REL/REF/SRC 及正文块身份不因改写/移动更换。删除保留修订墓碑，退休 ID 不复用；初始有效84不含 KU-049/073，但合法新增/拆合不受硬编码84限制。笔记、图形、视觉对象、资料版本、对话、任务、请求、操作有独立身份。
- `CourseService` 为运行时统一边界，feature 通过 `register_namespace(name, validator)` 扩展，复用同一 store/catalog/command lock；不得各建数据库、队列或直接写权威文件。初始化已在第一次知识/图读取前建立 `service.content` 恢复 journal，catalog 读锁与命令锁共享。

## 2. HTTP v1

成功返回 JSON 对象，错误返回 `{error:{code,message,details}}`。`not_found/source_unavailable` 为404，`revision_conflict` 为409，`save_failed/executor_unavailable` 为503，`capability_unavailable` 为501，其余通常400；空结果不是错误。POST 使用 `application/json`，提供 Origin 时须为当前端口 localhost/127.0.0.1；通常上限2,000,000字节，资料上传64 MiB。

| 入口 | 返回/请求 |
| --- | --- |
| `GET /api/v1/health` | `{status,courseId,instanceId}`，用于单实例识别。 |
| `GET /api/v1/course` | `{course,catalog,view,state,capabilities,contentProvider?}`；capabilities 表示已接入功能，不保证本机 CLI/模型当前可用。 |
| `GET /api/v1/entities/<id>` | 既有查询模块实体（保留 reading）；编辑须用下方 raw 内容入口。 |
| `GET /api/v1/graph?view=main\|auxiliary\|all` | 权威图、关系身份、布局；不从显示标签推导前置。 |
| `GET /api/v1/knowledge/<operation>` | search/related/path/questions，具体参数见下文。 |
| `GET /api/v1/state` | CourseStore 快照。 |
| `GET /api/v1/events?after=<sequence>` | 持久提交事件，JSON轮询续读，不是模型 delta 流。 |
| `POST /api/v1/commands` | 个人/阅读/布局或 knowledge 标准命令，见第3节。 |
| `GET /api/v1/content/<id>` | `{id,entity,hash,revision,generation,deleted}`，完整原始实体与 CAS 基线。 |
| `GET /api/v1/history` | `{versions:[{versionId,sequence,generation,label}]}`。 |
| `POST /api/v1/history/undo` | `{operationId}`，返回指定操作的逆向提交回执。 |
| `POST /api/v1/history/restore` | `{sequence,operationId,generation}`，保存恢复点并增加代际。 |
| `GET /api/v1/agent/state` | 对话、任务、状态询问、资料更新和侧栏偏好。重开旧活跃任务会核对执行器。 |
| `GET /api/v1/agent/models` | 启动独立 app-server、读取实际模型列表和 CLI 版本后关闭；并非纯静态配置查询。 |
| `POST /api/v1/agent/conversations` | `{}`新建；`{conversationId,patch:{draft?,title?}}`保存。 |
| `POST /api/v1/agent/requests` | 固定目标的学习请求，见第5节。 |
| `POST /api/v1/agent/control` | `{taskId,action:stop\|continue\|resolve,...}`。 |
| `POST /api/v1/agent/prompts` | `{promptId,status:keep\|weak\|todo}`，确认掌握状态。 |
| `POST /api/v1/agent/material-updates` | `{updateId,action:later\|update,conversationId?}`。 |
| `GET /api/v1/materials` | `{sources:[{sourceId,title,type,versions}]}`。 |
| `POST /api/v1/materials/import` | `{operationId,sourceId?,title,name,contentBase64,affectedUnitIds?}`，资料版本导入。 |
| `POST /api/v1/content/import` | `{packagePath,courseId?}`，导入本机已存在的内容包；不是上传正文 JSON。 |
| `GET /api/v1/sources/resolve` | 指定资料版本与位置，见第7节。 |
| `POST /api/v1/source-selections` | `{sourceId,versionId,location,text?}`，核对选段后返回真实文本或页上下文。 |
| `GET /api/v1/search?q=…&scopes=…` | 本地关键词四类检索，见第7节。 |

知识查询参数沿用现有模块：`search?q=&entity=unit&limit=20`；`related?id=&relation=requires&direction=upstream&depth=1&view=all`；`path?from=&to=&relation=requires`；`questions?id=&role=all|direct|support`。保留 AND/OR、direct/support、稳定顺序和明确错误。

## 3. 命令、CAS、幂等与提交事件

快照为 `{courseId,generation,sequence,documents}`；documents 按 namespace/key 保存 `{value,revision}`。未创建修订为0，已有知识初始修订为1，删除后修订仍非零。`GET content` 的 entity 是完整 raw 实体，不可用 entities 的派生摘要反写。

```json
{
  "operationId": "OP-stable-id",
  "actor": "student",
  "kind": "knowledge.edit",
  "generation": 1,
  "expectedRevisions": {"knowledge:KU-055": 3},
  "expectedHashes": {"knowledge:KU-055": "读取时的实体摘要"},
  "changes": [{"namespace": "knowledge", "key": "KU-055", "value": {"id": "KU-055", "其余字段": "完整原始实体"}}]
}
```

示例只说明结构，不能以省略实体实际提交。actor 仅 student/agent/import；changes每次1–200项，每个目标都提供 `expectedRevisions[namespace:key]`。删除写 `{namespace,key,delete:true}`。`expectedHashes` 为可选的严格当前知识摘要检查，键同为 `knowledge:<id>`；依赖端点等未修改对象也可列入版本/hash检查。全部目标先校验、一次原子提交，任一冲突不部分保存，details给出对象、当前修订及精确路径。

相同 operationId 和相同完整命令返回原回执，不重复写入；同ID不同载荷明确拒绝。回执含 `operationId/commitId/courseId/generation/sequence/saved/revisions/changes/savedAt`；内容命令额外有 `knowledgeChanges`，重放也保留这一形状。只有实际落盘后 `saved:true`。失败保留课程已提交状态和未确认草稿；丢回执重试原操作和原载荷，不偷换最新内容或基线。

每次 get/apply/history/undo/restore 检查未完成 journal 和外部知识变更；内容同步按原始内容比较，不只看mtime/size，登记外部 import 事件及实体修订。浏览器处理 HTTP 回执时不得把它的 sequence 直接当“所有事件已消费”游标，否则会跳过队列中的其他提交。事件序号、模型输出片段和阅读上下文修订各有用途，不混用。

`baseValues:{"knowledge:<id>":原始基础实体}` 可对陈旧修订做三方合并，基础须与该修订真实历史一致。按稳定块ID/字段合并；字符串、无ID数组视为整个片段，同一text/latex不猜测字符合并。若要使用旧基础合并，不同时传旧 `expectedHashes`，后者仍要求严格匹配当前值。冲突路径如 `/reading/blocks/@RB-…/payload/text`。

知识创建支持 KU、REL、路线组（G*/RG-*）；actor=import可新增SRC。已有Q/SRC可更新，内容包不得删除正式实体。完整知识校验仍来自课程模块；正文块ID、来源、coverage等保留，实际 reading变化重新分配单调修订。正式关系要求非空sourceRefs/value、合法端点/方向/环及路线组双向成员一致，OR组与关系增删需同一命令，不能静默降成AND。

### 存储与恢复保证

个人提交、修订、账本、历史与事件在同一SQLite事务。知识正文仍只写权威JSON，SQLite当前 knowledge值仅记hash，历史/恢复点可存实体前后像，但不是另一份可独立编辑的当前正文。

知识提交顺序为：完整校验/CAS → durable journal → SQLite写事务内再次CAS → 同目录临时JSON fsync/replace/目录fsync → 历史/事件/去重/版本COMMIT → 清journal。中断后按operations账本前滚或回滚；无关外部导入保留，同片段外部变更保留文件和journal并报带paths的save_failed。锁顺序为 `service._command_lock → 知识路径旁.content.lock → SQLite`，POSIX flock / Windows byte-range lock；Windows分支尚未实机验收。

这些锁只约束合作写入者。任意外部进程在最后检查与rename之间直接写文件，单方advisory lock不能排除覆盖窗口；正式在线导入必须走第6节入口。

## 4. 当前 namespace 与历史操作

| namespace / key | 职责 |
| --- | --- |
| `knowledge / TH-KU-Q-REL-SRC等实体ID` | 标准命令使用完整raw实体；当前SQLite值仅摘要，实际内容位于权威JSON。 |
| `notes / NOTE-…` | noteId/objectId/text/anchor，独立身份与修订；原对象失效后保留。 |
| `review / KU-…` | todo/weak/mastered，仅有效B；A计算汇总，不改重要性。 |
| `reading / default` | camera/selected/mode/history/expanded/revealed/inputs/panels/sourceView/relationMode/inputMode/filter等；来源位置与滚动、搜索和阅读进度不重定义执行中任务目标。 |
| `layout / VE-…或DRAW-…` | 个人位置/尺寸覆盖权威默认布局；不发明语义关系。 |
| `annotations / DRAW-…` | line/wave/highlight/rectangle/ellipse/arrow与anchor，几何写同名layout。 |
| `semanticChanges / KU-…` | needs-review/consistent及blockIds/reason，独立核对提示。 |
| `editingDrafts / <编辑键>` | 草稿、原始CAS基线与待重试完整命令；不是已保存正文。 |
| `conversations / CHAT-…` | 多段学习对话与真实messages，消息不另当可回退正文。 |
| `tasks / TASK-…` | 固定请求、执行器映射、运行状态、operationIds、通知/恢复事实。 |
| `agent_ui / default` | 当前对话、模型、侧栏、选择及草稿上下文。 |
| `reviewPrompts / PROMPT-…` | 实质变化后的学生状态选择，确认时检查原review修订。 |
| `materialUpdates / UPDATE-…` | pending/update/later的资料更新意图。 |
| `materialImports / <operationId>`、`contentImports / <packageId>` | 导入请求身份、摘要、轻量收据，不复制正文。 |
| `sourceTracking / observed` | 已观察的来源版本，防止重复提示。 |

`ContentCommands` 的 Python 接口：`get/read/apply/undo/restore/versions/history/writer_lock`。read额外给 `value=entity`。undo默认操作ID为 `undo:<原ID>:<当前generation>`，同代际重复撤回返回原回执；重做是撤回逆操作。知识按字段/块核对，保留后来不同块及个人内容；个人对象逆向要求精确修订，冲突整组拒绝。

`restore(sequence, command?)` 默认恢复知识及 notes/annotations/review/reading/layout/semanticChanges，先保存before_restore节点，再增加generation和实体/个人/reading修订。tasks/conversations、导入/更新记录、事件序号、去重账本与执行事实保留；新来源资源仍可解析旧/新引用。相同sequence有多个检查点时取最后一个；Python省略command视为新回退请求，HTTP必须显式operationId/generation以便安全重试。旧代际任务失去提交资格，即使正文值与历史相同也不能重新通过。

可选 `changed(result)` 回调在释放内容锁后执行；通知失败时回执仍可为 `saved:true` 并含notificationError，不能声称通知已确认。公共service已有统一通知时不再重复注册回调。

## 5. 学习请求、Agent工具与并发

```json
{
  "requestId": "REQ-stable-id",
  "conversationId": "CHAT-existing-id",
  "requestKind": "edit",
  "instruction": "明确的学习请求",
  "target": {"objectId": "KU-055", "blockId": "RB-stable", "text": "实际选段"},
  "sourceSelection": {"sourceId": "SRC-C05", "versionId": "指定版本", "location": {"pdfPage": 4}},
  "model": "用户选择的可用模型"
}
```

requestKind为ask/edit/search/update_sources；conversationId/sourceSelection/model及target的blockId/text可省略，objectId必需。requestId必须REQ-开头，相同ID同载荷去重，不同载荷拒绝；任务与user消息持久化后才放入缓存并启动。目标、选段、来源版本、意图、提交时实体和generation冻结；修改队列开始时重读同一目标最新正文，浏览其他单元不改目标。应用对话与独立执行会话分开保存。

当前 `CodexExecutor` 以本机CLI正常登录运行独立 `codex app-server`，stdio JSONL；initialize/model-list、thread/start、turn/start/steer/interrupt、thread/read负责生命周期。当前代码 `ephemeral:false`、read-only、approvalPolicy=on-request、effort=high，不复用当前桌面聊天；模型省略则沿用CLI配置。模型发现会起进程，重开旧任务核对也可能连接CLI；纯文档维护不调用这些入口。版本兼容与真实模型证据见运行基线第3/5节。

| 动态工具 | 实际输入和边界 |
| --- | --- |
| `review_get` | `{unitId}` → raw实体/hash/revision/generation/deleted，保存本任务读取基线。 |
| `review_search` | `{query}` → 课程真实关键词命中（最多30）。 |
| `review_source` | `{sourceId,versionId,location}` → 指定版本正文/原页；没有可读PDF文本时工具回复可带实际页图，并记sourceCitations。 |
| `review_locate` | `{hits:[{scope,id,versionId?,location?}]}`，最多50；按实际实体/来源解析验证，不能伪造命中。当前知识定位到单元，描述性对话命中不承诺与关键词消息定位相同精度。 |
| `review_edit` | `{unitId,baseHash,edits,summary,materialChange,materialReason}`；先get，edits每次1–100块。已有块给blockId和完整payload，可显式sourceRefs；新增给blockId/newBlock完整块，仅paragraph/formula/callout/interactive，追加在顶层末尾。不得提交脚本。 |

Agent工具写入限edit/update_sources；ask/search即使调用review_edit也拒绝。现有块需与本任务读取基线一致；其他块的学生变化保留，目标块已改则revision_conflict，要求重读或询问。新块保持身份/来源/受支持语义，不把意图层的“整理/扩展”误解为已支持任意删除、拆合或任意块类型。最后整实体提交仍以最新revision/hash/generation检查。

Agent操作ID由task/generation/unit/baseHash/edits构造；相同工具重放通过原命令取完整回执，提交与任务关联可由账本重建。`saved:true`才可称已保存；实质变化生成独立reviewPrompts，默认不自动改mastered。个人笔记、重要性与无关对象不在模型自动改写范围。

同课程跨对话修改共享队列，问答/搜索不占写队列。任务状态为queued/running/needs_input/completed/failed/interrupted/reconciling；部分提交后仍有冲突必须needs_input。非Agent知识变化通知正在运行/等待输入且读过该对象的任务；turn/steer发送最新raw内容并记accepted/error，accepted不能绕过最终CAS。兼容也说明同时修改位置与保留方式，通知未确认不得虚报。

控制：stop先持久撤销提交资格再interrupt，保留已提交；continue仅用于interrupted/failed/needs_input且执行器已退出，可附instruction/model，核对并携带已提交IDs后补剩余意图。重开只reconcile，不自动新turn；可从匹配turn的items恢复已完成回答，无法确认则needs_input。resolve仅回应当前真实pendingRequest，带`response`对象并核对threadId/turnId/执行器；失效请求需继续任务，不能回复旧审批。执行权限与内容直接生效分开，不凭空增加采纳门槛。

## 6. 内容包与资料版本导入

从项目根使用唯一在线安全入口：

```bash
python3 legacy/review-board/import_content.py 内容包.json
python3 legacy/review-board/import_content.py --course /临时课程副本 内容包.json
```

CLI包路径相对当前cwd解析成绝对路径；直接HTTP的相对packagePath按课程根。CLI核对runtime/health的courseId和instanceId，活跃服务时转POST content/import；服务拒绝或回执丢失不启第二写入者，重试同一包。无服务时持有同一CourseLock临时建立CourseService，完成后关闭，不开浏览器/Agent/常驻HTTP。

`review-content-package-1`仅为提案，含packageId/ticketId/baseSourceHash/baseEntityHashes/unitIds/units及questionUpdates/sourceProposals/assets/evidence。按拥有实体哈希判冲突，不因别的单元已导入而整包误拒。共享Q同候选幂等，不同候选冲突；保留身份、来源版本、资源命名空间及其他作者成果。运行时不继续读分包正文库。

`import_content_package(service,path,course_id?)` 在content.writer_lock内恢复、重读、stage/校验资源、应用候选并只取units/questions/sources实体diff，通过content.apply一次提交；同次保存contentImports轻量收据。资源先落盘再提交引用；失败可留可复用的未引用资源，不能留半份权威正文。启动含register_imports，重开可直接undo导入。主线在导入释放锁后通知Agent。

固定operationId为`OP-IMPORT-<packageId>`，摘要为整包规范JSON。同包重试即使发生后续编辑或历史回退仍返原回执；同packageId换内容拒绝。无正文diff也保存收据，返回`status:unchanged`。回执附packageId/unitIds/status，不复制正文。

**底层 `tools/digital-logic/复习内容.py import` 尚未参与运行时 `.content.lock`，不可与学生/Agent并发写权威文件。** 历史记录中的 `期中/工具/复习内容.py` 是迁移前位置；外部修改检测不等于消除这个race，正式导入用上方入口。

资料导入走materials/import和`MaterialImporter.add`：PDF/Markdown/TXT原字节保存为不可变版本，回执附sourceId/versionId/alreadyExists；同operationId重试去重。PDF页数由服务端pdfinfo核验，不信客户端数字；无效PDF或工具不可用明确失败，无heading文本可“全文”定位并保留尾换行。原件、版本元数据、导入收据和更新意图纳入共同命令。

更新提示ID为`UPDATE-`加`[sourceId,versionId]`规范JSON摘要。later不改正文/旧引用；update才发update_sources修改任务。新版本不会重解释旧引用，教材OCR绑定实际原PDF摘要，不能借旧版文字冒充新版。资料文件选择器浏览器链尚未通过，服务端导入通过不能替代该验收。

## 7. 来源、搜索、渲染与编辑接缝

来源与资源：

- `GET /api/v1/sources/resolve?sourceId=<SRC>&versionId=<VER>&pdfPage=<n>`；教材可bookPage，课程笔记可section，位置可含rect。返回版本/位置、textStatus、pageImageUrl/resourceUrl。先检查路径范围/版本摘要/页码，再查缓存；缺件、错版本、越界明确报错。
- `GET /source-pages/<SRC>/<VER>/<n>.png`渲染指定原页，`GET /source-files/<SRC>/<VER>`取该版本原件。页图缓存可重建；实例内同页锁、私有临时输出、成功原子发布，不同页可并发。跨实例只保证原子发布，不保证渲染去重；失败不删除其他发布者缓存。
- source-selections的text须存在于该页可核对文本；无可靠文字返回contentKind=page及实际页/选区上下文。浏览器`review-source-selection`保留sourceId/versionId/location/contentKind/text，由助手消费；不能捏造实际选中文字。
- `GET /course-assets/<packageId>/<path>`读取课程`期中/资源/<packageId>/…`；figure.asset为课程相对路径。应用字体/公式资源别名映射到experiments，与课程资源分开。
- `GET /api/v1/search?q=…&scopes=knowledge,notes,conversations,sources&limit=50`默认四范围、keyword模式。索引随知识sourceHash/个人sequence/来源文件变化失效重建；消息返回conversationId/messageId，知识返回blockId。单个原文版本不可读只在sources范围返回sourceWarnings，其他范围继续，修复文件后自行恢复。`mode=description`不由此本地检索器执行，应发Agent的search请求。

阅读提供器：`view`含units/themes/edges/sources/primaryIds/publishedIds/layout；publishedIds为reading complete单元，layout来自权威graph，个人layout可覆盖默认坐标。`units[*].reading`原样传递，缺provider不能宣称已完整渲染。`web/content/provider.js`提供`window.ReviewContentProvider.render(unit)`、`afterRender(root)`和可选captureState/restoreState；afterRender只初始化自己所属正文区的实际组件，保持幂等。`review-content-input`把交互输入与展开/答案一起交给公共阅读保存。`window.ReviewSourceTools`提供refsForUnit/load/search/renderSearchResults/captureSource/restoreSource，sourceView保存版本/页码/引用/选择/滚动。

正文`review-reading-1`含revision/status/blocks/coverage；块有稳定id/kind/role/payload/sourceRefs，可含children。kind为paragraph/formula/figure/table/steps/callout/knowledge-reference/example/exercise/interactive；role为core/material/supplement。必需条件不能藏起；example展开完整讲解，exercise提示/答案手动揭示。共享题干/标准解答归Q，完整children优先，避免重复题解；knowledge-reference只指稳定知识主位置，不复制全文。交互只允许`semantic_components.py`的受支持配置，当前为2:1/4:1 MUX、74LS138和现有跨边四格卡诺图；任意卡诺函数返回capability_unavailable，不能沿用旧示例输出。

### 编辑 host

加载本地MathLive、editing.css/js后调用`window.ReviewEditing.mount(host)`，返回`{refresh,flush,destroy,ownsGesture,controller}`。编辑器不直接fetch/localStorage/写文件，也不自建history。

| host入口 | 合同 |
| --- | --- |
| selectedUnit / getEntity | 取得选择并固定编辑目标；异步getEntity提供完整raw及hash/revision/generation。 |
| applyContent(command) | 统一knowledge CAS/历史，回执更新host快照再刷新；不是第二次直接存文件。 |
| personalEntries(namespace) | 全局所有单元`[{key,value,revision}]`，含墓碑，不只当前选择。 |
| applyPersonal(changes,kind,metadata) | metadata含operationId/groupId/expectedRevisions；用编辑器捕获的修订，不能提交时取最新以掩盖冲突。图形+layout原子提交。 |
| onRefresh(handler) | 快照/正文DOM/历史更新后通知，返回unsubscribe；refresh核对锚点但保留打开草稿。 |
| undo / redo / history | undo原操作返回新逆操作ID，redo撤回逆操作。当前integration提供undoOperationId/redoOperationId游标，不承诺任意多步UI历史栈；整幅恢复独立入口。 |
| stageDraft / recoverDrafts | 复用editingDrafts；恢复含读取时session/raw/hash/revision/generation，`pending:<key>`保留原完整命令。无法还原安全基线的草稿给复制入口，不套新基线。 |

编辑正文命令使用完整raw深拷贝，只改受支持payload字段，保留id/role/sourceRefs/children/coverage。引用正式Q不改KU中的伪副本；interactive不开放任意JSON/脚本。编辑器的`expectedEntityHashes:{id:hash}`由integration转换为标准`expectedHashes:{'knowledge:'+id:hash}`；`semanticImpact`转换为同次semanticChanges命令，并在受影响interactive.payload.semanticStatus标needs-review。无法证明同步时保存编辑并显示“探索结果需核对”，不能继续称旧计算一致。`materialChange/materialReason`另用于掌握状态询问。

`relation.create`是**前端host接缝，不是HTTP直接识别的业务路由**：携带expectedEntities、fromUnitId/toUnitId/type/directed/value/sourceRefs/view及可选requirementGroupId/route；integration分配REL-ID、转换knowledge变更，以端点hash检查，必要时同命令更新已有路线组。requires由前置指向后继，inverse须双向；UI必须选真实来源，最终课程校验拒绝非法关系。新生成的ID、基线与最终载荷在首次POST前冻结以便重试。普通手画arrow永远只写annotations。

笔记为`{noteId,objectId,text,anchor,createdAt,updatedAt}`；图形为`{drawingId,objectId,tool,color,anchor,…}`，同名layout含局部block/单元CSS像素坐标x/y/width/height/flipX/flipY。anchor记录objectId/blockId/revision/originalText/sourceRefs和可选selector `{exact,prefix,suffix,start,end}`；重关联保留originalAnchor/relocations及原NOTE/DRAW身份。明确合并目标/唯一片段可跟随，歧义、删除、退休或不能唯一定位则保留在全局待重关联库，不复制。来源读取失败不当作删除。

笔记连续输入约900ms或失焦保存；图形/单元变换pointerup单组保存，pointercancel/Escape零命令。单元布局键`VE-KU-…`的x/y是主题内坐标，width/height为border box；host负责更新world/主题边界、关系和小地图，编辑器只临时预览。主画板手势排除editing UI/overlay/contenteditable/math-field，正文选取可用；空格/中键交回平移，第二指取消笔画。overlay按稳定块定位，不把派生hint/answer DOM ID当新块；flush有冲突、destroy尚未保存均reject，不能无提示丢草稿。

## 8. 迁移与维护验证

停服务后整体复制课程（清单、权威知识/布局、来源版本、资源、`.review-board/`），另带兼容应用代码、仓库tools/digital-logic与experiments运行资源；正常退出合并WAL，运行中备份须一致数据库快照，不只拷贝正在写的单个SQLite。数据路径解析使用选定课程根，工具与应用资源由仓库定位；不能仅复制HTML或浏览器缓存。恢复后验证同courseId、新instanceId、知识/个人/任务/来源位置一致，字体/公式/原页实际加载。

知识与教材命令均从仓库根运行，默认课程为 `courses/digital-logic/`：

```bash
python3 tools/digital-logic/知识地图.py get KU-055
python3 tools/digital-logic/知识地图.py check --source-only
python3 tools/digital-logic/知识地图.py check
python3 tools/digital-logic/textbook/教材.py verify
python3 tools/digital-logic/textbook/教材.py search '5.55' --chapter 5 --scope exercises
python3 tools/digital-logic/textbook/教材.py read 179-180
```

地图生成和正文校验通过既有工具接口使用；不因整理文档重建课程、重新OCR或运行底层正文导入。在线并发导入始终使用第6节的 `python3 legacy/review-board/import_content.py`。

专项测试入口与命令由README维护，避免重复命令清单；可用tests/test_content_commands.py、test_content_imports.py、test_material_import.py、test_agent_runtime.py、test_anchors.py、test_sources.py及persistence/integration/agent/editing/board客户端测试定位行为。文档维护不需要启动Agent；异常恢复使用临时课程和执行器端口替身，不改个人库。
