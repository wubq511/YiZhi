# CourseService 实施接口

状态：2026-10-26。01–04已集成本地服务、84单元正文、Agent、编辑和标注，并通过完整课程联合验收。运行时写入知识通过统一内容命令，个人状态与独立布局不进入正文。

## 文件与运行边界

- 课程根为当前项目文件夹，启动后创建 `课程.json` 和 `.review-board/状态.sqlite3`。清单中的位置均为课程相对路径；正式知识仍位于 `期中/数据/知识地图.json`，布局仍位于 `期中/数据/视图布局.json`。
- 应用代码在 `复习画板/`。过渡读取已认可原型的四个正文样本，不在这里再维护正文副本；样本资料和依赖仍从现有演示目录提供。
- 个人状态采用 SQLite 原子事务，操作账本、修订和事件与修改一起提交；浏览器草稿缓存只用于未确认保存的恢复，不能代替课程文件。

## HTTP v1

响应为 JSON。成功直接返回下述对象；错误为 `{error: {code, message, details}}`，使用相应非 2xx 状态，不能当作空结果。

| 路径 | 内容 |
| --- | --- |
| `GET /api/v1/health` | 课程 ID、服务实例 ID 和实际运行状态 |
| `GET /api/v1/course` | `course` 清单、`catalog` 规模、`view` 阅读数据、`state` 个人状态快照、`capabilities` |
| `GET /api/v1/entities/<id>` | 既有模块的实体，保留 reading 与原有字段 |
| `GET /api/v1/graph?view=main|auxiliary|all` | 既有图接口，不从显示标签推断关系 |
| `GET /api/v1/knowledge/<operation>` | search / related / path / questions；参数按既有查询模块 |
| `GET /api/v1/state` | CourseStore 快照 |
| `GET /api/v1/events?after=<sequence>` | 持久化的递增事件，可重连读取 |
| `POST /api/v1/commands` | 校验后提交知识实体或个人内容、阅读、布局命令 |
| `GET /api/v1/content/<id>` | 原始实体、hash、revision、generation；供编辑 CAS 使用 |
| `GET /api/v1/history` | 整幅历史版本与提交序号 |
| `POST /api/v1/history/undo` | `{operationId}`，选择性撤回指定操作，返回新操作回执 |
| `POST /api/v1/history/restore` | `{sequence,operationId,generation}`，保留恢复点并增加代际 |
| `GET /api/v1/agent/state` | 对话、任务、未处理状态询问、资料更新和侧栏偏好 |
| `GET /api/v1/agent/models` | 当前 CLI 实际可用模型及 CLI 版本 |
| `POST /api/v1/agent/conversations` | 空对象新建；`{conversationId,patch:{draft?,title?}}` 保存 |
| `POST /api/v1/agent/requests` | 固定目标学习请求，见下文 |
| `POST /api/v1/agent/control` | `{taskId,action:stop|continue|resolve,...}` |
| `POST /api/v1/agent/prompts` | `{promptId,status:keep|weak|todo}`，确认掌握状态 |
| `POST /api/v1/agent/material-updates` | `{updateId,action:later|update,conversationId?}` |
| `GET /api/v1/materials` | 来源及其不可变版本目录 |
| `POST /api/v1/materials/import` | `{operationId,sourceId?,title,name,contentBase64,affectedUnitIds?}` |
| `POST /api/v1/content/import` | `{packagePath,courseId?}`，02 内容包导入到同一命令账本 |

快照包含 `courseId`、`generation`、`sequence` 和 `documents`。documents 按 namespace、key 组织；每个值为 `{value, revision}`，未创建对象修订为 0。删除保留修订墓碑。

命令包含 `operationId`、`actor`、`kind`、`generation`、`changes`、`expectedRevisions`。changes 每项为 `{namespace,key,value}` 或 `{namespace,key,delete:true}`；expectedRevisions 以 `namespace:key` 为键。全部目标先校验修订，再原子提交。同一操作 ID 的相同请求返回原结果，载荷不同则拒绝。

提交返回 `operationId`、`commitId`、`courseId`、`generation`、`sequence`、`saved`、`revisions`、`changes`、`savedAt`。saved 只有真实持久化后才为 true。冲突为 `revision_conflict`，保留服务器内容和浏览器未保存草稿。

## 当前 namespace

| namespace / key | value |
| --- | --- |
| `notes / NOTE-…` | `noteId`、`objectId`、`text`、`anchor`；对象笔记 anchor 指向稳定 KU，保留当时引用 |
| `review / KU-…` | `status` 为 todo / weak / mastered |
| `reading / default` | camera、selected、mode、history、expanded、revealed、inputs、panels、source、relationMode、inputMode、filter 等当前阅读上下文 |
| `layout / <visual-id>` | 视觉位置/尺寸，独立于知识语义；当前主要读取既有稳定布局，后续编辑通过同一命令接入 |
| `annotations / DRAW-…` | 六种个人图形、稳定 anchor；几何坐标写 layout 同名键 |
| `semanticChanges / KU-…` | 绑定组件的 `needs-review` 提示，不能声称旧计算与新公式一致 |
| `editingDrafts / <编辑键>` | 未确认编辑组与原始 CAS 基线；重试使用同一完整命令 |
| `conversations / CHAT-…`、`tasks / TASK-…` | 持久学习对话、任务、执行器轮次与操作关联 |
| `agent_ui / default` | 侧栏宽度、当前对话、选段、模型和草稿上下文 |
| `reviewPrompts`、`materialUpdates` | 等待学生选择的掌握变化与资料更新意图 |

#03/#04 若需要新增命令或 namespace，由公共注册扩展接入，不能各自写状态文件。历史回退时代际/修订和去重账本不能倒退。

## 内容与任务命令

知识变化使用 `namespace:knowledge`、稳定实体 ID 和完整原始实体，并提供 `expectedRevisions`；`expectedHashes` 可补充读取时的实体摘要。正文块 ID 和原引用保持稳定，`reading.revision` 单调递增。选择性撤回按字段/块三方核对，不能把完整旧快照覆盖后来内容。`materialChange:true` 和 `materialReason` 可声明结论/方法实质变化，内容保存后生成独立状态询问，确认前原掌握状态保留。

学习请求为 `{requestId,conversationId?,requestKind:ask|edit|search|update_sources,instruction,target:{objectId,blockId?,text?},sourceSelection?,model?}`。同 requestId 的相同载荷去重；变更载荷须新 requestId。目标、选段、来源版本、意图与代际在提交时冻结，修改任务开始时重新读取该目标最新内容。

Agent 状态包含 queued/running/needs_input/completed/failed/interrupted/reconciling。每次执行保留独立 threadId/turnId 与已提交 operationIds；停止先取消提交资格再发送 interrupt。重开仅核对执行器与本地提交账本，不静默启动新 turn；显式继续只补未完成意图。普通问答/搜索调用写工具会被拒绝。

执行中学生修改通过 `turn/steer` 通知，任务记录 `accepted` 与错误，提交仍核对最新块和课程代际。兼容的不同块可以整合，同块变化需重读或明确询问。支持的交互语义由 `semantic_components.py` 提供，未知配置返回 capability_unavailable；不允许提交后继续显示另一组数据的结论。

## 给 02 的读取接缝

`view` 的 `units/themes/edges/sources/primaryIds` 保持现有原型消费形状，全部身份由知识模块提供。`publishedIds` 列出 reading 已完成的单元；`layout` 原样传递权威 `graph` 的主题、单元和关系视觉绑定，画板据此保持课程阅读顺序，个人 `layout` 文档仍可覆盖默认坐标。`units[*].reading` 原样传递；浏览器内容提供器优先使用 reading，否则只读使用现有样本。reading 的渲染实现由 #02 提供，#01 的笔记与状态绑定 KU，不绑定正文 HTML。

#02 可将渲染器置于 `复习画板/web/content/` 并导出 `window.ReviewContentProvider`：`render(unit)` 返回正文 HTML 或 null，`afterRender(root)` 初始化本渲染器的组件。没有 renderer 时，reading 仍可从实体接口读取，不会被当作“完整正文已渲染”。界面注册与渲染集成由 #01 收拢，避免改同一份 app.js。

## #02 已接入的来源、搜索与资源接口

- `GET /api/v1/sources/resolve?sourceId=<SRC>&versionId=<VER>&pdfPage=<n>`：返回指定版本的原件定位、文本状态及 `pageImageUrl/resourceUrl`；教材可用 `bookPage`，课程笔记用 `section`。版本不匹配、文件缺失和页码越界分别报错。
- `GET /source-pages/<SRC>/<VER>/<n>.png`：从指定版本渲染原页；缓存可重建。`GET /source-files/<SRC>/<VER>` 返回指定版本原件。
- `POST /api/v1/source-selections`：JSON 为 `sourceId/versionId/location/text?`。text 必须实际存在于该页可核对文本；无 text 返回真实页/选区上下文，不伪造选中文字。浏览器选择结果同时触发 `review-source-selection` 事件，供 #03 使用。
- `GET /api/v1/search?q=<text>&scopes=knowledge,notes,conversations,sources`：默认四类，结果含稳定 ID、版本、摘录和定位；索引随知识sourceHash、个人状态sequence及来源文件变化失效重建。对话按真实消息索引并返回conversationId/messageId；知识命中保留blockId。单份原文不可读不会阻断其他范围，sourceWarnings仅随sources范围返回真实版本与已知页/小节诊断。`mode=description` 由 #03 接入。
- `GET /course-assets/<packageId>/<path>`：读取课程内 `期中/资源/<packageId>/…`，正文 figure 的 `asset` 使用课程相对 `期中/资源/...` 路径。
- `window.ReviewSourceTools` 提供 `refsForUnit/load/search/renderSearchResults/captureSource/restoreSource`。来源页码、引用列表和文本选择保存在阅读上下文的 `sourceView`，重开恢复。
