# YiZhi 旧版运行基线

此目录保留已完成的 Python／Web 应用；下一版 Electron 设计见 [系统设计定稿](../../docs/architecture/系统设计定稿.md)。默认课程在 `courses/digital-logic/`，共享运行资源在 `experiments/`。

20主题、84有效单元的完整正文已与保存恢复、真实Agent、编辑标注接入同一个本地应用，并于2026-10-26通过联合验收。本应用读取唯一权威reading；详见[整课验收](验收/整课联合验收-2026-10-26.json)。

## 打开

macOS 双击 [启动复习画板.command](启动复习画板.command)，或从项目根运行：

```bash
python3 legacy/review-board/start.py
```

默认地址为 `http://127.0.0.1:8769/`。同一课程再次启动会打开已有实例；终端 Ctrl-C 停止。可指定 `--port 0` 自动选择端口、`--no-browser` 仅启动服务，或 `--course /课程文件夹` 打开迁移后的课程。

本地阅读与编辑使用 Python 标准库和现有资源；PDF 原页、文本提取需要本机 Poppler。学习助手另需已安装并正常登录的 Codex CLI，沿用 CLI 当前配置或在侧栏选择模型，无需另填 API key。本轮真实接入版本为 `codex-cli 0.163.0`，问答与修改使用独立 app-server 会话。

## 保存在哪里

- 课程根的 [课程.json](../../courses/digital-logic/课程.json) 保存稳定课程身份及相对路径。
- `.review-board/状态.sqlite3` 保存对象笔记、B 的三态、独立阅读/布局状态、对象修订、幂等记录、提交事件和历史。一次修改与其记录在同一 SQLite 事务里提交。
- 正文与正式关系写回唯一的 `期中/数据/知识地图.json`；内容命令使用文件锁、持久日志与 SQLite 账本共同恢复。个人笔记、三态、布局与任务记录独立保存，不写回重要性评级。
- 浏览器仅缓存尚未确认保存的草稿。显示“已保存到课程”后才代表文件落盘；连接失败时保留草稿，恢复服务后可重试。另一窗口改过同一内容时明确选择，不静默覆盖。

课程整体备份时先停止服务，再复制整个课程文件夹，包括原始资料、来源版本、`期中/`、`课程.json` 与 `.review-board/`。运行代码与共享资源由 YiZhi 仓库提供，恢复旧版课程时使用兼容的 `legacy/review-board/` 和 `experiments/`。不要只复制 HTML 或只复制浏览器缓存。正常停止会将 SQLite WAL 合入主数据库；运行中备份需使用数据库快照，不能只拷贝一个正在写入的数据库文件。

## 已实现的阅读路径

对象笔记与复习状态绑定稳定 KU；状态为待复习、薄弱、已掌握，主题只汇总，可在目录按状态筛选。导航、三级显示深度、原位展开、练习揭示、引用返回、画板操作和三项视觉要求沿用已认可的样本。

重新打开可恢复视口、当前单元、导航返回栈、展开、提示/答案、交互输入、目录/小地图、输入模式、搜索/筛选，以及来源阅读区和滚动位置。正文提供器的输入通过同一阅读上下文保存，换成正式 reading 不另建个人笔记库。

API、扩展方法和 02/03/04 的接缝见 [接口.md](接口.md)。原型和新正文的组件初始化按所属区域隔离，避免一个正文模块重绘其他组件。原型源码未被改作个人状态数据库。

## 学习助手与编辑

选择单元或拖选正文，在“学习助手”里提问；原文区可携带真实选段与页码。普通回答保存在对话中，选择“修改画板”或点击“加入画板”才写入正文。可切换多段对话和模型，修改按课程排队，阅读和问答仍可继续。任务执行期间的手动修改会通知 Agent；同块冲突保留学生内容并提示处理。完成提供“前往目标”，不强制切换视口。

“编辑与标注”提供文字、MathLive 公式、独立片段笔记、直线、波浪线、荧光笔、矩形、椭圆、个人箭头及移动/尺寸。手画箭头不改变知识关系；正式关系需通过独立入口明确端点、类型、方向、价值与已有来源。原块失效的笔记和标注仍可在库中找到，并保留原语境重新关联。

知识有明确的合并目标，或拆分后只有一个对应片段时，笔记和图形保持原身份跟随，并保存最初语境与引用；对应不明确时留在库中等待重新关联，不复制到多个对象。调整单元高度后，过长内容可内部滚动，重开恢复该位置。

任务或编辑操作可选择性撤回；“历史版本”恢复整幅内容并先保留恢复点，课程代际和修订继续递增，任务事实与去重记录不回退。停止会保留已提交结果并拒绝后续提交；重开先核对执行器记录，未完成部分需点击“继续”。

资料版本支持 PDF、Markdown、TXT。保存新版保留原版本；“暂不更新”保留画板与旧引用，“根据新版更新”才发起明确修改。教材 OCR 与其原始 PDF 摘要绑定，新增版本不能借用旧版文字。已掌握单元发生实质变化时询问是否调整状态；手动编辑可明确勾选“这次编辑改变了重要结论或方法”。公式无法转换为现有交互语义时，编辑仍保存，探索结果明确标记为“需核对”。

新增交互支持 2:1/4:1 MUX、74LS138，以及现有跨边四格卡诺图示例。其他卡诺图函数目前只支持文字与公式解释，不能提交后继续显示旧例子的结论。

## 02 内容包导入

在项目根使用统一入口，活跃服务会接收 HTTP 导入，无服务时持有课程锁：

```bash
python3 legacy/review-board/import_content.py 内容包.json
```

并发正式导入须使用此入口。底层 `tools/digital-logic/复习内容.py import` 尚未参与运行时的内容锁，不可与学生或 Agent 修改同时写权威文件。具体合同见 [内容包与资料导入](接口.md#6-内容包与资料版本导入)。

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tests python3 -B -W error::ResourceWarning -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/persistence-client.test.cjs tests/integration-client.test.cjs tests/agent-client.test.cjs tests/editing-client.test.cjs
```
