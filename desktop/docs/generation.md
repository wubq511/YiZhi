# 从新增来源生成一个小主题

Agent 侧栏的「从来源生成小主题」固定一个已登记 PDF 版本及最新已确认解析页，再接收学生的范围和学习目标。当前只支持 TI SN74HC153 功能表的一个低有效通道：固定 Gbar=0，B=S1、A=S0、C0..C3=I0..I3、Y=Z。新主题和单元使用明确新身份；画板锚点 KU-001 的既有语义保留。已生成主题可显式选择更新，保留单元与角色块 ID。

完整讲解包含学习目标、信号解释、必要推导、公式、表格、带解答例题及带提示和答案的练习；第二个独立一致组追加一道练习。有效组自动发布，没有逐块采纳。当前发布的是阅读材料，不增加可执行实验定义，也不扩展到电气、时序、第二通道或任意算法证明。

## 读取、校验和提交

宿主的真实 app-server 只获得 `yizhi_read_generation_context`、`yizhi_publish_lesson`、`yizhi_query_lesson` 等窄工具。实际用户输入在任务快照中；每次读取持久记录 task/attempt/generation、来源摘要、解析产物摘要、目标正式修订、学生草稿基线、图目标和各项用途。候选保留实际输入及逐论断文字项依据。未标记 PDF 的定位文字和原页 raster 不被称为原生 Table 标签或 OCR。

Core 分别记录结构、身份、引用、版本、课程一致性、来源含义、有限域计算、实验适用性结果。来源含义检查限定为该表的低有效使能、符号映射及四种选择码；它不是一般中文断言验证器。引用必须落到真实表格行、必要表头或禁用态单元格；页上的无关文字不能作为依据。公式独立对照来源 L/H/X 行展开的 64 组输入，例练核对完整六位输入、选通行和答案。没有新增实验时，实验检查明确为不适用。

发布事务再次核对当前 task/attempt/generation、来源与最新解析产物、正式目标、学生最新草稿和活动编辑保护。未进入持久草稿的编辑尾部同样会保留候选。来源内容或目标结构变化要求重读；只追加练习时沿用已确认讲解，不要求重发讲解的全部论断。旧正式内容、旧固定引用及个人批注原文保留。

## 未完成、停止和恢复

侧栏分别显示正式保存回执、当前已确认阶段、剩余阶段及未发布候选。展开候选可读实际草稿和各层失败原因；新回执出现后更新候选列表。模型 turn 结束本身不代表校验或发布完成。

停止先撤销写资格，已有正式回执仍为事实。核对原任务后，由学生明确继续建立新尝试，重新读取当前依据，只处理剩余阶段。`generation_candidates` 与共享 `cg_history` 保存原候选／回执事实；`generation_groups` 是当前阶段确认的投影。整课恢复后重新检查正式块身份，已被恢复移除的阶段不能仅凭旧回执跳过；重建阶段仍保留原历史事实。

新建单元的正文、结构、图节点、主题及布局有完整 before/after；正式历史可作为一致组撤回和恢复。图节点、主题及主题布局分别使用单调对象修订，独立主题的后续创建不阻挡原组撤回；同一对象 A→B→A 仍产生冲突。单元头部与正文分别核对，标题修订也可按原组恢复。SQL 事务完成后才更新图的运行内存。撤回后的个人批注原文保留为待关联；精确恢复相同历史块提供 restoration proof 后重新关联。整课恢复同时使用 T22 的新 session/generation 边界；旧 session 可查原回执，不能重新取得发布资格，范围外新增主题保留。

生命周期版本投影由 Core 维护；普通正文命令只可读取正文、结构、引用和依赖对象，不能取得这些单元或图对象的写域。旧库按已有整图修订建立对象版本基线，保留旧修订的保护，不改写历史回执。

## 验证

`tests/generation.test.ts` 经公共 CourseService 验证来源解析、完整自动发布、候选、输入保护、稳定身份、来源变化、停止继续、历史生命周期、事务回滚、ABA 和跨整课恢复。`tests/generation-ui.spec.ts` 经真实 Electron/IPC 验证来源绑定、1024×688／700×700 及受控失败候选查看；协议夹具不代表真实模型通过。

`tests/generation-real-source.test.ts` 使用独立准备课程中的官方完整 PDF。设置 `YIZHI_T30_PREPARED_COURSE` 运行真实原页读取；另设 `YIZHI_T30_ACTUAL_MODEL=1` 才调用真实模型，`YIZHI_T30_STOP_CONTINUE=1` 验证实际停止后显式继续。`YIZHI_T30_MODEL` 和 `YIZHI_T30_CLI_PATH` 可选用实际目录中模型和本机真实 CLI。`YIZHI_T30_EVIDENCE_DIR` 将一次性课程副本及任务／候选／正式内容证据保留到指定诊断目录；未设置时清理副本。外部执行失败、超时和未完成均使测试失败，不能替代成功发布及重开验收。
