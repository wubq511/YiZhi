# 正式历史、选择性撤回与单元旧版

顶栏「课程历史」查看全课活动；正文「单元历史」限定当前 B。同一 Agent 原任务和继续任务按实际 operationId 汇成一项活动，不重复计算继承回执。学生连续编辑按五分钟展示分组，原提交边界不变。展开显示时间、修改者、说明、对象及实际前后内容。旧版是只读投影；退出返回进入前的阅读相机与仍有效的焦点／选区，历史页中的 Undo 不修改当前课程。

`CourseService.formalHistory`、受限 preload 和 `src/history-api.ts` 共用 `list/detail/preview/apply/query`。列表分页只读取可重建的 `history_index` 元数据；正文留在已有 `operations`／`cg_history`／`placement_history`，不建立全课快照或第二套事件溯源内容。索引 INSERT 触发器与原正式提交处于同一事务。既有库按确认时间／游标补元数据；旧学生记录只能沿实际版本链反推修订，不以同值判定未被改过。

撤回按一致组逆序执行。对象版本保护 ABA；本次逆操作的中间版本沿原链比较，目标集合之外的学生修改不跳过。每组有 SQLite savepoint，冲突整组保留，无依赖组可部分成功。运行中任务先经宿主 T19 stop 撤销原尝试资格；Core 再封住同一逻辑任务的全部尝试，并重新核对实际提交集合。停止与真正执行器结束仍是不同事实。

恢复旧版从当前对象与正式历史构造所选单元及必要一致域，默认不退回布局、个人笔记、复习状态和对话；布局需另选。正文／公式、实验定义、正式关系与引用共同验证。实验只恢复已存确定数据，不调用模型重造；当前运行现场保留为原采用定义，恢复定义在 SQL COMMIT 后发布为待迁移定义。批注原文和孤立笔记保留。

预览包含受影响对象、必要来源版本、相关草稿及版本指纹。执行重新核对，相关新改动或草稿使旧预览冲突。界面先排空包括活动 B 的全部输入，未完成公式仍是草稿，保存失败阻止预览／恢复。恢复是一项新的正式提交，可查询、再撤回；同 operationId 精确重试不重复执行。其他工作任务在同一事务收到新的 student-change 通知。

已支持的恢复对象是既有单元的递归块／有序结构、块间引用／依赖、正式关系／路线组、布局及内置实验定义。后续生产者的 `unit:`、`graph:`、`theme:` 等新结构域没有在此假定逆操作：列表可展示原正式记录，撤回整组明确冲突，跨该组的旧版恢复拒绝拆组。新单元创建／删除的图成员与个人内容生命周期需由实际后续整合扩展。整课代际恢复和期限清理分别属于 T22／T23。

验证入口：`tests/history.test.ts` 使用公共 CourseService 与临时 SQLite，覆盖版本链、冲突／部分结果、结构、批注、来源、故障回滚和重开；`tests/history.spec.ts` 驱动真实 Electron／IPC，包含原操作重试、700px 窗口、活动 B 保存失败和运行中任务撤回。运行中任务场景使用明确标注的协议夹具，未将它冒充真实模型生成验收。
