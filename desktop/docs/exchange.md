# 已有交换数据兼容

内容交换已按 [ADR-0008](../../docs/adr/0008-product-development-boundary.md) 退出产品。正式应用不提供所选单元／批注交换包的检查、导入或导出，不维护旧包写入器；整课画板分享本期不做。完整课程携带与恢复使用[完整备份](backup.md)。

已经导入课程的正文、关系、固定来源、图片和个人批注属于该课程的正式数据，继续正常读取、编辑和备份。`exchange_resources` 等旧表保留必要资源登记，已用过的操作身份仍受去重保护；不会因为名字含 exchange 就清空数据或重新分配身份。

通用 `CourseService.resources.read` 只读取当前会话已登记的图片并核验摘要与长度。资源保留根、课程历史、来源读取和独立备份均由正常运行模块承担，不再通过交换或旧课迁入构造器初始化。存量兼容回归见 `tests/imported-resources.test.ts`，旧版交换写流程与测试可通过 Git 历史追溯。
